# P3.4 — Build the user prompt renderer

Phase: 3 · Transcript rendering
Execution: **autonomous**
Depends on: P3.3

## Goal

Differentiate what the user sent with a quiet fill and role semantics, without conventional right-aligned chat bubbles.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing. The semantic document—not a view and not a
Markdown-library AST—is the source of truth. Preserve the agent/tile ownership split, light/dark
tokens, keyboard accessibility, and I5. Visible Aqua dropdown or rounded text-field styling is not
acceptable in new tile UI. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Use the semantic user surface, no outline/title/status word, and the same readable width as assistant prose.
2. Apply modest vertical inset and artifact/composer radius role.
3. Expose “You” as an accessibility role/label without drawing a permanent caption.
4. Support multiline Markdown blocks from the semantic entry.
