# P3.3 — Build the assistant prose renderer

Phase: 3 · Transcript rendering
Execution: **autonomous**
Depends on: P3.2

## Goal

Render assistant prose as the quiet reading path: no card title, border, or background, with selectable text and readable measure.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing. The semantic document—not a view and not a
Markdown-library AST—is the source of truth. Preserve the agent/tile ownership split, light/dark
tokens, keyboard accessibility, and I5. Visible Aqua dropdown or rounded text-field styling is not
acceptable in new tile UI. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Consume paragraph/heading/list/quote children through a temporary plain semantic stack until the rich inline renderer lands.
2. Use tile-body surface, primary text, horizontal reading inset, and no decorative container.
3. Expose semantic heading/list accessibility.
4. Keep the renderer isolated from the live tile in this ticket.

### Implementation sketch
