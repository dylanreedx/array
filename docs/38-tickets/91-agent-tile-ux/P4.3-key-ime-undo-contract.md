# P4.3 — Implement send/newline, IME, and undo key semantics

Phase: 4 · Composer
Execution: **autonomous**
Depends on: P4.2

## Goal

Match keyboard-first agent usage without breaking text systems that NSTextView already handles correctly.

## Approach

1. Enter emits send only when there is trimmed content and no marked IME text.
2. Shift+Enter inserts newline; Option/Command combinations retain standard text behavior unless documented.
3. Escape dismisses suggestions first; Stop is a separate intent, not a surprise Escape side effect.
4. Group programmatic completion insertion as one undo operation.

### Implementation sketch

```swift
if event.isReturn && !hasMarkedText() && !event.modifiers.contains(.shift) {
    delegate?.composerRequestedSend(self)
    return
}
super.keyDown(with: event)
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.

## Done when
