# P0.3 — Add semantic tile and interaction tokens

Phase: 0 · Foundations
Execution: **autonomous**
Depends on: P0.1

## Goal

Define the visual vocabulary needed by the new transcript/composer without changing the live tile or choosing ad-hoc colors in renderers.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing. The semantic document—not a view and not a
Markdown-library AST—is the source of truth. Preserve the agent/tile ownership split, light/dark
tokens, keyboard accessibility, and I5. Visible Aqua dropdown or rounded text-field styling is not
acceptable in new tile UI. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Add semantic roles for decorative hairline, semantic/focus outline, composer surface, artifact surface, selected row, hover row, and subdued code surface.
2. Raise or add radius roles for tile/composer/artifact while preserving existing roles until migration.
3. Document which lines are decorative and therefore outside the 3:1 component boundary rule; keep meaningful boundaries and text contrast gated.
4. Do not adopt the new values in a live view in this ticket, so no baseline moves.

### Implementation sketch

```swift
public enum AgentLineRole: CaseIterable {
    case decorativeHairline   // not state-bearing
    case controlBoundary      // interactive shape
    case focusRing            // keyboard focus
    case attention            // approval/error/warning
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.

## Done when

- Every new surface/text pair used by the future tile has light and dark leaves.
- The token checks prove semantic lines cannot be accidentally aliased to the decorative hairline.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
