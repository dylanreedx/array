# P4.5 — Add per-agent prompt history navigation

Phase: 4 · Composer
Execution: **autonomous**
Depends on: P4.4

## Goal

Make repeated and revised commands fast while preserving ordinary arrow-key movement in multiline text.

## Approach

1. Keep bounded per-agent accepted prompt history locally.
2. Up enters history only when selection is collapsed at the first visual line; Down only at last visual line/history mode.
3. Preserve the pre-navigation draft and restore it after the newest history item.
4. Deduplicate adjacent identical prompts.

### Implementation sketch

```swift
if key == .up && cursor.isAtFirstVisualLine { history.previous(preserving: currentDraft) }
else { super.keyDown(with: event) }
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.
