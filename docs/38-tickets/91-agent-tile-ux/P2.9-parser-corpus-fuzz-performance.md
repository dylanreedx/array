## Approach

1. Run the P0.4 corpus through parse→encode→decode→plain-text projection.
2. Generate deterministic malformed delimiters, nesting, Unicode, and chunk boundaries from a fixed seed.
3. Measure 5,000 streamed deltas with coalescing and assert parse count is bounded, not one per delta.
4. Print measured budgets and choose floors from repeatable local evidence with headroom.

### Implementation sketch

```swift
for seed in 0..<500 {
    let source = deterministicMalformedMarkdown(seed)
    let parsed = parser.parse(source, entryID: id(seed), previous: [])
    expect(parsed.plainText.containsAllUserScalars(from: source))
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.
