## Approach

1. Add one internal v2 construction seam used by QA/Component Lab and optionally a launch flag; default production remains old until P5.5.
2. Feed semantic document patches from the existing tile subscription; do not create a second event subscriber/model.
3. Integrate the P4.10-approved **full-turn composer** (1–8 visual lines, model/effort, Send/Stop, provider-enabled `/`/`@`/`$` completions) as the live tile's command surface, replacing the legacy single-line field on the v2 path; bind drafts, prompt history, and actions by attached AgentID and flush/cancel on detach.
3a. Add request-response composer variants **only where an explicit compiled response contract exists** (via P5.2's response-mode capability). Fixed-choice approval/question requests keep provider choices as buttons — never fabricate a text editor for them. The compact freeform shell and the optional-note reveal ("Write a note…") appear only when the provider-neutral seam explicitly exposes freeform or note permission for that request; `AgentRequestPayload`'s empty `choices` is not such a contract. Reuse composer behavior through the P4.10 variants rather than embedding the entire full-turn composer in request surfaces.
4. Route every explicit unresolved provider request to its semantic transcript request block: needs-attention affordances reveal that block, which shows the provider prompt/context and clearly labelled available choices (for example Approve/Decline only when those choices are actually supplied). Resolved history becomes passive and stale actions remain inert. Do not carry forward the legacy permanent approval dock.
5. Prove replay→tail exactly once, forced reattach, streaming, branch refresh, request reveal/action identity, and no runner ownership change. (Current-work/FileTree consistency proof moves to P5.3 when it unblocks.)
6. Compare legacy compatibility projection and v2 semantics during fixtures; explicit provider work remains read-only and no work is inferred from prose.

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.

## Done when

- Real supervisor fixture renders v2 from event replay and tail without duplicate nodes.
- The v2 tile composes prompts through the full-turn composer with AgentID-bound draft/history; no request surface gained a text editor without an explicit compiled response contract.
- A needs-attention state can reveal one matching request surface with explanatory context and real provider choices; no orphan label, fabricated choice, modal, or permanent approval dock remains.
- Detach cancels UI tasks but not the agent.
- I5 and all old checks remain green; no Continuum approval gate or second task manager exists.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
