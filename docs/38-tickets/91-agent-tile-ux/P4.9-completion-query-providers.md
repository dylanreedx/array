# P4.9 — Build extensible slash, file, and skill completion queries

Phase: 4 · Composer
Execution: **autonomous**
Depends on: P4.8

## Goal

Make `/`, `@`, and `$` suggestions provider-driven and replaceable without embedding three menus and parsers in the text view.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing. The semantic document—not a view and not a
Markdown-library AST—is the source of truth. Preserve the agent/tile ownership split, light/dark
tokens, keyboard accessibility, and I5. Visible Aqua dropdown or rounded text-field styling is not
acceptable in new tile UI. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Detect the active query around the caret with quoting/escape awareness.
2. Define async cancellable providers keyed by trigger.
3. Merge/dedupe/rank results deterministically and preserve provider provenance.
4. Provide static fixture providers now; Pi `get_commands`, file index, and skills adapters may register when available.
5. Insert replacement ranges as one undo operation.

### Implementation sketch

```swift
protocol AgentCompletionProvider: Sendable {
    var trigger: Character { get }
    func suggestions(for query: AgentCompletionQuery) async -> [AgentCompletion]
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples parsing, rendering, and agent execution.

## Done when

- Stale async results cannot replace suggestions for a newer query.
- Caret movement/detach cancels requests.
- Paths remain local and never enter sync metadata.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
