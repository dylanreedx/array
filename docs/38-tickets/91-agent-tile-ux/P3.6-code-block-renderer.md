# P3.6 — Build the code block renderer

Phase: 3 · Transcript rendering
Execution: **autonomous**
Depends on: P3.5

## Goal

Give fenced code a compact, selectable, copyable surface that can later accept syntax highlighting without changing the document/list contracts.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing. The semantic document—not a view and not a
Markdown-library AST—is the source of truth. Preserve the agent/tile ownership split, light/dark
tokens, keyboard accessibility, and I5. Visible Aqua dropdown or rounded text-field styling is not
acceptable in new tile UI. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Use a non-editable `NSTextView`/TextKit surface with monospaced token, horizontal scroll policy, language label, and custom copy affordance.
2. Show incomplete-stream state subtly without changing the code text.
3. Define a `CodeHighlighting` seam whose default is plain token styling; do not add a highlighter dependency yet.
4. Cap initial expanded height and allow internal scrolling for very long code.

### Implementation sketch
