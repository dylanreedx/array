# P3.2 — Typed Event Snapshot Frames

Phase: 3 · Typed protocol and production transport
Execution: **autonomous**
Depends on: P3.1

## Goal

Add typed event publish/batch, snapshot request/response, blob reference, and replay cursor frames using the provider-neutral semantic content contract.

## Context and design direction

Read `_DESIGN.md`, `_RUNBOOK.md`, `_DECISIONS.md`, and `_ACTION_ITEMS.md` before editing. The trusted relay is a durable small-team control/data mirror; execution hosts retain provider secrets and final authority over local resources. Class-B authenticated transcript/tool content may cross only through the typed protocol, while Class-C credentials, environment values, signing keys, raw process handles, and unrelated filesystem content remain host-only. Exactly one ticket and one fenced production/check change set belong in an iteration.

Class-B content is allowed only through explicit schemas and workspace authorization. This is the formal I5 replacement boundary; taint scanning remains defense-in-depth for legacy/Class-A paths.

## Approach

1. Add the already-reviewed `ContinuumRevivedAgentContent` dependency to RelayProtocol and update the P0.2 compiler/dependency guard so semantic values are allowed without opening Core/Sync/GRDB/NIO/UI imports.
2. Represent canonical mutation/event kinds explicitly; preserve unknown future semantic blocks as bounded opaque values, never executable HTML.
3. Carry generation/sequence cursors and snapshot through-sequence exactly.
4. Inline content has strict frame limits; large output uses authorized content-hash references.
5. Define Class A/B/C classification metadata and a schema-level forbidden Class-C field/value test corpus.

### Implementation sketch

```text
event.publish(agentID, hostEventID, semanticMutation)
snapshot(agentID, cursor, document)
blob.ref(hash, bytes, mediaKind)
```

The sketch fixes ownership and failure semantics, not exact spelling. Adapt names to compiled code without collapsing protocol, durable authority, network adapter, host execution, or client reduction into one type.
