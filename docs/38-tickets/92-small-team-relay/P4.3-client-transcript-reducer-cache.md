# P4.3 — Client Transcript Reducer Cache

Phase: 4 · Full-control host and phone flows
Execution: **autonomous**
Depends on: P4.2

## Goal

Build the shared relay transcript client reducer and bounded encrypted-at-rest iPhone cache over snapshots, events, receipts, and presence.

## Context and design direction

Read `_DESIGN.md`, `_RUNBOOK.md`, `_DECISIONS.md`, and `_ACTION_ITEMS.md` before editing. The trusted relay is a durable small-team control/data mirror; execution hosts retain provider secrets and final authority over local resources. Class-B authenticated transcript/tool content may cross only through the typed protocol, while Class-C credentials, environment values, signing keys, raw process handles, and unrelated filesystem content remain host-only. Exactly one ticket and one fenced production/check change set belong in an iteration.

The phone is a first-class client, not a metadata observer. It still needs safe local storage, cursor commit-after-apply, revocation behavior, and no executable rendering payload.

## Approach

1. Replace relay reuse of `CompanionAuthService.activeSessionTokens()` with a relay-specific credential store. Pair through the one-use exchange, confirm the relay identity fingerprint, and write the returned credential once to Keychain/non-syncing protected storage.
2. Reduce welcome/snapshot/event/receipt/presence frames into one platform-neutral client state and wire the iPhone app to that state without a second transcript model.
3. Persist applied cursors and bounded document snapshots using iOS Data Protection-compatible storage abstraction; key material never syncs through cloud backup by default.
4. On revoke, clear credentials immediately and apply the owner-approved cache retention/erase policy.
5. Expose non-executable semantic blocks to native renderers; unknown values remain bounded plain structured content.

## Watch out

- Do not put relay bearer credentials in the transcript cache.
- Do not accept a pairing URL that substitutes an unconfirmed relay identity or sends the one-use secret to another endpoint.
- Do not use UserDefaults for full transcript storage.
- A cache is not canonical relay backup.
- Never stage, commit, reset, clean, stash, branch, rebase, merge, push, or alter queue/loop machinery from a worker session; the harness owns those actions.
- If the packet conflicts with compiled reality or an unresolved owner decision, return `WORKER: BLOCKED <evidence>` rather than inventing a second architecture.
