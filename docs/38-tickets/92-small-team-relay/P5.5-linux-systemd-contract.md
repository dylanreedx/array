# P5.5 — Linux Systemd Contract

Phase: 5 · Operations and deployment
Execution: **autonomous**
Depends on: P5.4

## Goal

Add Linux source portability guards and a systemd unit/install contract without falsely claiming runtime portability until the final real-Linux gate.

## Context and design direction

Read `_DESIGN.md`, `_RUNBOOK.md`, `_DECISIONS.md`, and `_ACTION_ITEMS.md` before editing. The trusted relay is a durable small-team control/data mirror; execution hosts retain provider secrets and final authority over local resources. Class-B authenticated transcript/tool content may cross only through the typed protocol, while Class-C credentials, environment values, signing keys, raw process handles, and unrelated filesystem content remain host-only. Exactly one ticket and one fenced production/check change set belong in an iteration.

A low-cost VPS is plausible around the owner’s ~$5/month budget, but ContinuumRevivedSync/Core currently contain Apple-only dependencies. Only RelayProtocol/Core/NIO/executable service paths may enter the Linux build graph.

## Approach

1. Add a Linux graph/source guard rejecting CloudKit/AppKit/Security imports and Apple frameworks from relay server targets.
2. Render a hardened systemd unit: dedicated user, explicit state/config dirs, restart throttling, file permissions, no secrets in ExecStart, and conservative filesystem/process protections compatible with SQLite/blob writes.
3. Provide install/status/uninstall contract using temporary root; do not sudo in autonomous checks.
4. If Docker/remote Linux is owner-configured, check-relay-linux builds/runs the real health/restart smoke; otherwise it must report external evidence pending, not print “passed Linux.”

### Implementation sketch

```text
swift build --product continuum-relay   # inside supported Linux environment
systemd ExecStart=/opt/.../continuum-relay serve --config /etc/...
EnvironmentFile references protected secret file
```

The sketch fixes ownership and failure semantics, not exact spelling. Adapt names to compiled code without collapsing protocol, durable authority, network adapter, host execution, or client reduction into one type.
