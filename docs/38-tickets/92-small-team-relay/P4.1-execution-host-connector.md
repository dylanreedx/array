# P4.1 — Execution Host Connector

Phase: 4 · Full-control host and phone flows
Execution: **autonomous**
Depends on: P3.10

## Goal

Implement the outbound execution-host connector that authenticates as one environment, advertises its sanitized catalog, consumes commands, and publishes liveness without turning SSH into the app protocol.

## Context and design direction

Read `_DESIGN.md`, `_RUNBOOK.md`, `_DECISIONS.md`, and `_ACTION_ITEMS.md` before editing. The trusted relay is a durable small-team control/data mirror; execution hosts retain provider secrets and final authority over local resources. Class-B authenticated transcript/tool content may cross only through the typed protocol, while Class-C credentials, environment values, signing keys, raw process handles, and unrelated filesystem content remain host-only. Exactly one ticket and one fenced production/check change set belong in an iteration.

The host connector lives near agent/provider ownership and uses RelayProtocol/V2Transport. It never exports raw processes, provider credentials, environment values, absolute paths, or a generic shell surface.

## Approach

1. Put the portable connector and an injected `RelayHostGateway` protocol in RelayClient. Add RelayClient as a dependency of ContinuumRevivedCore, while preserving the rule that RelayClient never imports app/provider types.
2. Load relay URL/environment credential from an injected secret source; connect outbound through `RelayClientTransport`.
3. Implement `ContinuumRelayHostGateway` as the Mac adapter to AgentSupervisor/provider ownership and project configured projects/providers/models to opaque catalog IDs and safe labels.
4. Register command handlers by exact typed command; re-authorize catalog revision and local policy before acknowledging.
5. Publish heartbeat independently from agent status and stop cleanly on logout/sleep/network transitions.

### Implementation sketch

connector.onCommand { cmd in

## Watch out

- Do not make the relay final authority over host resources.
- Do not send provider configuration just because it is needed to label a model.
- Do not use SSH as the persistent transport.
- Do not make the portable connector import ContinuumRevivedCore; future Linux hosts must be able to provide another gateway implementation.
- Never stage, commit, reset, clean, stash, branch, rebase, merge, push, or alter queue/loop machinery from a worker session; the harness owns those actions.
- If the packet conflicts with compiled reality or an unresolved owner decision, return `WORKER: BLOCKED <evidence>` rather than inventing a second architecture.
