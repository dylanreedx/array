# P1.7 — Lint: no raw colors, no semantic colors on custom fills
Phase: 1 · Depends on: P1.3 · Tag: autonomous · Execution-mode: medium

## Goal
Without enforcement the debt regenerates — it already has, three times over
(`AgentsBoardProjection` colorTokens, iOS `AppColors`, `zoneTint` are three parallel vocabularies).
Make the rule mechanical.

## Files
- `scripts/check-color-hygiene.sh` (new)
- `scripts/run-matrix.sh` (register as a leg)
- `docs/38-tickets/90-agent-ux/color-hygiene-allowlist.txt` (new, committed)

## Approach
Grep-based gate over `Sources/ContinuumRevived/Canvas/`, `Sources/ContinuumRevived/App/`, and
`ios/Continuum/Sources/`:
1. **Ban raw color construction**: `NSColor(red:`, `NSColor(srgbRed:`, `NSColor(calibratedRed:`,
   `NSColor(white:`, `Color(red:`, `UIColor(red:`.
2. **Ban system semantic colors used as, or on, a custom fill**: flag `.labelColor`,
   `.secondaryLabelColor`, `.tertiaryLabelColor`, `.separatorColor`, `.primary`, `.secondary`,
   `Color(.tertiaryLabel)` in the same file as a raw fill — the precise pattern that produced
   tonight's black-on-dark bug.
3. Every existing violation goes in the allowlist with a `# reason` and the ticket that will remove
   it (P1.10 / P1.11 / P1.12). The gate fails on any violation **not** in the allowlist, and also
   fails if an allowlisted line no longer exists (so the list can't rot).

## Done when
The gate runs in the matrix, currently-known violations are allowlisted with owners, and a newly
added raw color fails the build.

## Verify
Add `NSColor(red: 1, green: 0, blue: 0, alpha: 1)` to a Canvas view → matrix red naming file:line →
revert. Remove an allowlisted line → the gate reports a stale allowlist entry.

## Watch out
- Do not allowlist wholesale (e.g. a whole file or a glob). Line-scoped entries only, each with a
  reason and an owning ticket — otherwise this becomes theater.
- `ComponentLab` and `*Checks` files legitimately construct colors for fixtures and witnesses;
  exclude those paths explicitly in the script, with a comment, rather than allowlisting hundreds
  of lines.
