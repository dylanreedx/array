# P3.3 — Attention as a separate axis from state
Phase: 3 · Depends on: P3.2 · Tag: autonomous · Execution-mode: medium

## Goal
State says *what the agent is doing*; attention says *whether it is yours*. Conflating them is why a
finished-but-unseen agent looks identical to one you already reviewed.

## Files
- `Sources/ContinuumRevivedAgentUI/AgentInboxRow.swift`
- `Sources/ContinuumRevived/App/AgentSupervisor.swift` (read-state, local only)

## Approach
```swift
public enum InboxAttention: Equatable, Sendable { case none, unread, woke }
```
`unread` = the agent completed a turn while you were not looking at it, cleared when its tile is
focused or the row is opened. `woke` = a snoozed agent raised its hand (Phase 4). Read-state is
**local desktop state, not synced** — store it beside the agent record, keyed by `AgentID`.

## Done when
A completed-and-unviewed agent reports `.unread`; focusing it clears to `.none`.

## Verify
Checks: turn completes while unfocused → `.unread`; focus → `.none`; a turn completing *while*
focused never sets `.unread`; `woke` outranks `unread` in the label priority from P3.2.

## Watch out
- Do not sync read-state (it is per-human, per-device, and I5-irrelevant).
- Clearing on *hover* is wrong — it must take a deliberate focus/open, or unread becomes useless.
