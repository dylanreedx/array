# P3.13 — Inline rename
Phase: 3 · Depends on: P3.6 · Tag: autonomous · Execution-mode: low

## Goal
Agents get auto-titles; a human needs to name the one that matters.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`
- `Sources/ContinuumRevived/App/AgentSupervisor.swift` (persist `displayName`)

## Approach
Double-click the title → inline `NSTextField`; Enter commits, Esc cancels, blur commits. Persist via
`supervisor.rename(agentID:to:)` → `AgentRecord.displayName` → `AgentStore`. Reuse the zone
inline-rename pattern already in the codebase (`--zone-rename-inline-check` exists) rather than
inventing interaction semantics.

## Done when
Rename persists across relaunch and appears everywhere the name is shown.

## Verify
Check modelled on `--zone-rename-inline-check`: commit on Enter, revert on Esc, commit on blur, empty
name rejected (keeps the previous name).

## Watch out
- The name may cross to the phone; it is user text, so keep it short and treat it as a label, never a
  path. Trim whitespace.
