# P4.6 — Snooze raised hand: early wake
Phase: 4 · Depends on: P4.5, P4.2 · Tag: autonomous · Execution-mode: medium

## Goal
A snooze must never hide something that needs you. But it also must not un-snooze for things you had
already seen when you snoozed it.

## Files
- `Sources/ContinuumRevivedAgentUI/AgentLifecycle.swift`
- `Sources/ContinuumRevivedAgentUIChecks/AgentLifecycleChecks.swift`

## Approach
`raisedHandWhileSnoozed(record:now:) -> Bool`, true when any of:
- a pending approval or pending user input exists
- a failure **newer than** `snoozedAt`
- a run **completed after** the snooze was set

The newness test is the subtle part: snoozing an agent that had *already* failed keeps it snoozed —
that snooze meant "I saw it, not now." Requires storing `snoozedAt` alongside `snoozedUntil`.

A raised hand surfaces the agent with attention `.woke` (P3.3), which outranks `unread` in the label
priority.

## Done when
Blockers and *new* failures wake a snoozed agent; a pre-existing failure does not.

## Verify
Checks: pending approval while snoozed → woken; failure at `snoozedAt - 1s` → **stays snoozed**
(this is the witness); failure at `snoozedAt + 1s` → woken; run completing after the snooze → woken;
nothing happening → stays snoozed until `snoozedUntil`.

## Watch out
- Needs `snoozedAt` persisted (P4.1 stores `snoozedUntil`; add the companion field here and note the
  schema addition).
- Do not clear the snooze on wake — represent it as "woken" so the user can re-snooze without losing
  that it had been deferred.
