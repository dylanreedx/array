# P5.6 — Make `/compact` real
Phase: 5 · Depends on: P5.2 · Tag: autonomous · Execution-mode: medium

## Goal
`/compact` currently goes to the model as literal text and it *lies* — it replied "Context compacted."
having done nothing. Pi's built-in slash commands are interactive-only; the rpc `compact` command is
the real thing.

## Files
- `Sources/ContinuumRevived/App/AgentSupervisor.swift`
- `Sources/ContinuumRevivedCore/AgentProviders/PiRpcClient.swift`

## Approach
`compact` (optionally with instructions) plus `set_auto_compaction`. Surface the result in the
transcript as a distinct marker — the session format has a `compaction` entry type with its own usage,
so a compaction is a real event, not a message. Expose auto-compaction as a per-agent setting.

## Done when
Compaction runs on demand, the transcript shows it, and context usage drops measurably (P5.8's meter).

## Verify
**Deterministic:** fake client asserts a `compact` command is sent (not a prompt containing the text
"/compact" — that is the bug being fixed, and is the witness); a `compaction` entry renders as a marker.
**Manual:** compact a long real session and watch the context meter fall.

## Watch out
- Wiring `//compact` in the composer is P6.5's job; this ticket is the capability. Do not build the
  slash parser here.
