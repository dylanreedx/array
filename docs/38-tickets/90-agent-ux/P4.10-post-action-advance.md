# P4.10 — Post-action advance, validated at completion
Phase: 4 · Depends on: P4.2, P3.11 · Tag: autonomous · Execution-mode: medium

## Goal
Email-style flow: settling the agent you are viewing moves you to the next one — without ever yanking
you somewhere you did not ask to be.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach
After a settle/snooze/archive completes, advance selection to the next row in the visible list. The
critical detail: validate against the **current** selection/route at *completion* time, not at dispatch
— if the user navigated elsewhere while the action was in flight, do nothing. Where nothing follows,
fall back to the previous row, then to no selection.

## Done when
Settling the viewed agent advances; navigating away mid-action does not move you.

## Verify
Check: settle row 2 of 5 → selection is the row that was 3; settle the last row → previous row;
simulate the user selecting row 5 before the action completes → **selection unchanged** (witness).

## Watch out
- With multi-select (P3.11), advance past the whole affected set, not one row.
