# P1.11 — Adopt tokens in tile chrome and canvas
Phase: 1 · Depends on: P1.10 · Tag: autonomous · Execution-mode: high

## Goal
Fix why the canvas "looks like mush" independent of the text bug: **tile borders measure 1.68:1**
(`white 0.25` on `white 0.10`), so tile edges dissolve into the canvas. Also unify the eleven
per-`TileKind` fills in `DescriptorTileNSView` and the independently re-declared
`white 0.10`/`white 0.90` pairs across the other tile views.

## Files
- `Sources/ContinuumRevived/Canvas/TileNSView.swift` (body/border/title-bar/status-pill/brackets)
- `Sources/ContinuumRevived/Canvas/DescriptorTileNSView.swift` (~:35-45, eleven fills)
- `Sources/ContinuumRevived/Canvas/CanvasNSView.swift` (zone chrome, selection, marquee)
- `Sources/ContinuumRevived/App/WorkspaceSidebarView.swift`, `App/WorkspaceTopBarView.swift`
- `Sources/ContinuumRevived/Canvas/{FileTile,NoteTile,RunArtifacts,FileTree,DiffReview}TileNSView.swift`

## Approach
Route every fill/text/border through tokens + `applyTokens()`. `borderStrong` for tile edges so
they clear 3:1 against `canvas`. Replace `NSColor(calibratedRed:…)` in `FileTreeTileNSView` with
sRGB tokens — calibrated RGB drifts the rendered color off the tested luminance (ticket 87
watch-out #1). Keep the eleven descriptor fills semantically distinct but derive them from the token
set rather than eleven bespoke literals.

Also replace the seven unnamed magic offsets in `TileNSView.drawAgentStatus` (`+18`, `-58`, `y: 4`,
`+6`, `-3`, `+15`, `+2`) with named `Space`/`Metrics` values — the `-58` is an undocumented
dependency on the close button + drag-dot layout.

## Done when
Tile edges are visibly distinct from the canvas (≥3:1, asserted), no raw color literals remain in
these files, and the P1.7 allowlist entries for them are deleted.

## Verify
Matrix green with P0.4 contrast asserting `borderStrong` vs `canvas` ≥3:1 in both themes, plus
P0.5's `expectVisibleBorder` on a tile. Baselines will change across many components — review the
diff images before blessing. `--ui-tour-check` sheet should show tiles reading as distinct objects.

## Watch out
- This touches many files; keep it a single mechanical adoption and resist redesigning any tile.
- `chromeScale`/zoom-aware sizing in `TileNSView` must keep working — tokens supply base values, the
  existing scale math still applies.
- If the diff gets unmanageable, split by file group and mark the remainder blocked with a note
  rather than half-adopting.
