# P3.5 — In-flight fade
Phase: 3 · Depends on: P3.2, P3.3 · Tag: autonomous · Execution-mode: low

## Goal
Counter-intuitive but correct: rows that are **working or blocked-and-waiting recede**; rows that are
**finished-unread or failed stay full strength**. Prominence belongs to what needs a human —
"working threads aren't your problem yet."

## Files
- `Sources/ContinuumRevivedAgentUI/AgentInboxRow.swift` (a derived `emphasis` property)
- the list view (P3.6)

## Approach
Pure derivation: `emphasis(for: state, attention:) -> RowEmphasis` (`.full` | `.receded`).
`.receded` = `working` or `input`/`approval` *not yet acted on*… careful: an approval **needs you**, so
it must stay FULL. Recede only `working` (and `ready` already-read). Failed and unread stay full. The
status label keeps its accent even when the row recedes, so waiting rows remain findable.
Hover/selection/active clears recession.

## Done when
A working agent is visibly dimmer than a finished-unread one, and an approval is never dimmed.

## Verify
Checks over the full state × attention matrix: assert `.receded` exactly for {working, ready+read};
assert `.full` for {approval, input, failed, ready+unread, woke}. Regression witness: receding an
approval must FAIL.

## Watch out
- The opacity value is a token (P1.3), not a literal, and the receded text must STILL clear 4.5:1 —
  fading is not a licence to fail contrast. Assert the faded pair too.
