# Colour hygiene allowlist — P1.7
#
# Every colour violation that existed when the gate landed, one source line at a
# time. `scripts/check-color-hygiene.sh` is red on anything here that no longer
# exists, and red on any violation that is not here — so this file only ever
# shrinks. There is no regenerate/bless mode: an allowlist a worker can rewrite
# is the theatre the ticket warns about.
#
# Format, one entry per line, directly under a `# <reason> · owner: <ticket>`
# comment:
#     <path>:<occurrences>:<the offending source line, trimmed>
# Occurrences count identical lines in the same file, so adding one more copy of
# an already-excused line is still red. Entries are line-scoped by construction:
# the key IS the line's text, and the gate rejects an entry whose text is not
# itself one of the two banned patterns — a file or a glob cannot be excused.
#
# Owners:
#   P1.10 — Sources/ContinuumRevived/Canvas (tile surfaces adopt DesignTokens)
#   P1.11 — Sources/ContinuumRevived/App    (chrome adopts DesignTokens)
#   P1.12 — ios/Continuum/Sources           (iOS consumes the same tokens)
