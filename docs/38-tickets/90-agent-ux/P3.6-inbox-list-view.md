# P3.6 — The AppKit inbox list view
Phase: 3 · Depends on: P3.4, P3.5, P1.10 · Tag: autonomous · Execution-mode: high

## Goal
Replace the sidebar's workspace/zone/tile tree with the agent inbox as the **default** content.
Workspace/project become a scope dropdown (P3.8) and row metadata — never group headers.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift` (new)
- `Sources/ContinuumRevived/App/WorkspaceSidebarView.swift` (host the inbox)
- `Sources/ContinuumRevived/App/ComponentLab.swift` (register a Lab entry per state)

## Approach
Follow `WorkspaceSidebarView`'s existing conventions: `NSOutlineView` (`.sourceList`) or
`NSTableView`, value-tree input, and the `…ForQA` accessor convention a new surface is expected to
mirror. Card row ≈78pt, three lines:
```
[project chip] title                      Working 4m
               role · model
               branch #123        +12 −4          [glyph]
```
Rows come from `sortForInbox` (P3.4); emphasis from P3.5; colours/type/spacing from tokens (P1.x).
Use `AgentInboxRow.id` for diffing (P2B.7's change-set) — do not full-reload on every event.

## Done when
The sidebar shows agents by default, including headless ones, with correct state/attention/emphasis.

## Verify
Geometry (P0.3), contrast in both appearances (P0.4/P1.6), pixel probes (P0.5), and committed
baselines (P0.6) for one Lab entry per state × variant. Plus a `--agent-inbox-check` asserting row
count/order matches the model and that a headless agent appears.

## Watch out
- Do not delete the zone/tile tree wholesale in this ticket if anything still depends on it — host the
  inbox first, migrate consumers, and note what remains.
- Preserve the QA accessors other checks use (`--workspace-sidebar-*-check` legs must keep passing;
  P0.11's inventory guard will catch it if a leg disappears).
