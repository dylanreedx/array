# P1.10 — Adopt tokens in the agent tile and transcript cards
Phase: 1 · Depends on: P1.3, P1.4, P1.5, P1.9 · Tag: autonomous · Execution-mode: high

## Goal
Make the surface the owner actually looks at consume the design system, and retire its literals.
This is where the tokens stop being theory.

## Files
- `Sources/ContinuumRevived/Canvas/ManagedAgentTileNSView.swift`
- `Sources/ContinuumRevived/Canvas/TranscriptCardViews.swift`
- `Sources/ContinuumRevived/Canvas/ApprovalDockView.swift`
- `Sources/ContinuumRevived/Canvas/UserInputCardView.swift`

## Approach
Replace every literal color with a token, every font size with a `TextRole`, every padding/radius
with `Space`/`Radius`/`Inset`, and every status color with `StatusChipPresenter` (P1.8). Adopt
`TokenThemed.applyTokens()` (P1.9).

Two known-bad specifics to fix while here, both proven by measurement tonight:
- Card **body** text must be a primary text token (it is the content of the tile; it was rendering
  in a secondary grey at 12pt).
- Metadata must not use a tertiary-grey equivalent — it measured **2.25:1** on every card fill and
  fails AA outright.

Derive the approval dock's height from type metrics (`Metrics.rowHeight`) instead of the hardcoded
92pt, which cannot satisfy three side-by-side buttons at the 320pt minimum tile width.

Remove the corresponding entries from the P1.7 color-hygiene allowlist in the same commit.

## Done when
No raw color/size/padding literals remain in these four files; the P1.7 gate passes with those
allowlist entries deleted; the tile renders correctly at 320/640/900pt in both themes.

## Verify
`./scripts/run-matrix.sh` — P0.3 geometry, P0.4 contrast (both appearances), P0.5 pixel probes,
P0.6 baselines, P1.7 hygiene all green. Baselines will change: inspect the diff images, then bless
deliberately and note it in the commit body. Also render `--ui-tour-check` and confirm the tile
appears correct in the contact sheet.

## Watch out
- Do not change layout structure here — the width pins, scroll-to-bottom, and per-turn card split
  are already correct and load-bearing. This is a styling adoption, not a rewrite.
- Blessing baselines is expected in this ticket, but **only** after confirming the diff is the
  intended token change and nothing else moved.
