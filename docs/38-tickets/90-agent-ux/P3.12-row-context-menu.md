# P3.12 — Row context menu
Phase: 3 · Depends on: P3.11 · Tag: autonomous · Execution-mode: low

## Goal
Per-row actions where the hand already is. The sidebar has **no context menus at all** today.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach
`menu(for:)` on the row: Open in tile · Settle / Un-settle · Snooze › (presets, Phase 4) ·
Wake · Mark unread · Rename · Stop agent · Archive · Delete. Items are enabled per the same
capability rules as bulk (P3.11). "Stop agent" is the **explicit** stop — closing a tile must never
stop an agent (P2A.5). When a multi-selection exists and the click is inside it, the menu acts on the
selection and says so (`Settle (3)`).

## Done when
Right-click offers the correct enabled set for one row and for a selection.

## Verify
UI check: menu item titles/enablement for a running vs ready vs settled agent; selection-aware titles.

## Watch out
- Snooze/settle items are inert until Phase 4 lands — either hide them or disable with a tooltip; do
  not wire them to nothing silently.
