# P4.1 — Lifecycle state: tri-state override + timestamps
Phase: 4 · Depends on: P2A.2, P3.1 · Tag: autonomous · Execution-mode: medium

## Goal
Make "I'm done with this" a real, persisted, reversible fact — the thing that turns a status list into
an inbox. **Locked: full settle/snooze/archive.**

## Files
- `Sources/ContinuumRevivedAgentUI/AgentLifecycle.swift` (new, pure)
- `Sources/ContinuumRevivedCore/Agents/AgentRecord.swift` (add the fields)
- `Sources/ContinuumRevivedAgentUIChecks/AgentLifecycleChecks.swift` (new)

## Approach
```swift
public enum SettledOverride: String, Codable, Sendable { case settled, active, neutral }
public enum InboxLifecycle: Equatable, Sendable { case active, snoozed(until: Date), settled, archived }
```
On `AgentRecord`: `settledOverride: SettledOverride` (default `.neutral`), `settledAt: Date?`,
`snoozedUntil: Date?`, `archivedAt: Date?`. Decode-forward like the rest of the record.

The tri-state matters: `.settled` is "I said done", `.active` is an explicit **keep-active pin** that
suppresses auto-settle, `.neutral` lets the auto rules decide. A two-state boolean cannot express the pin.

**`archived` ≠ `settled`.** Settled stays in the list (slim, readable); archived leaves it.

## Done when
Fields exist, persist, round-trip, and default to `.neutral`/nil.

## Verify
Checks: Codable round-trip incl. dates (use `timeIntervalSinceReferenceDate` like `AgentActivityEvent`
— `timeIntervalSince1970` is lossy); a record from before this ticket decodes with `.neutral`.

## Watch out
- Do not compute `InboxLifecycle` here — that is P4.2's pure function. This ticket only stores facts.
- Lifecycle is desktop state. It may cross to the phone later, but do NOT add it to the sync payload here.
