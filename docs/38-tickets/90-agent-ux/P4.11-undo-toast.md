# P4.11 — Undo toast
Phase: 4 · Depends on: P4.10 · Tag: autonomous · Execution-mode: low

## Goal
Every lifecycle action is reversible, and the reversal should be right there — a mis-aimed snooze on a
30-agent list is otherwise very annoying to find and fix.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach
A transient toast after settle/snooze/archive: "Snoozed until 18:00 · Undo". Undo restores the
*previous* lifecycle values exactly (`settledOverride`, `settledAt`, `snoozedUntil`, `snoozedAt`) —
capture them before mutating rather than reconstructing them afterwards. Auto-dismiss ~6s; one toast at
a time; a bulk action reports its count ("Settled 3 · Undo") and undoes as one unit.

## Done when
Undo restores the exact prior state, including for a bulk action.

## Verify
Check: snooze → undo → all four fields equal their captured values (witness: reconstructing rather than
restoring must FAIL when the agent was previously `.active`-pinned); bulk settle of 3 → undo restores all 3.

## Watch out
- Undo must not un-settle something that was *already* settled before the action.
- Do not use the toast for errors; it is an undo affordance, not a notification channel.
