# P3.11 — Multi-select with bulk actions
Phase: 3 · Depends on: P3.6 · Tag: autonomous · Execution-mode: medium

## Goal
Triage several agents at once — the payoff when six finish together.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach
Click / shift-click range / ⌘-click toggle, with a stable anchor for range extension. Bulk actions
appear only when **every** selected row can take the action (T3's rule) — a mixed selection does not
offer "Settle" if one member is blocked. Bulk set: settle · snooze › · mark unread · archive · delete.
Archive/delete must be disabled while any selected agent is running.

## Done when
Range and toggle selection work; bulk actions are correctly enabled/disabled.

## Verify
Checks over selection sets: enablement is the AND across members (regression witness: enabling an
action when one member cannot take it must FAIL); a scope change clears selection (P3.8).

## Watch out
- Destructive bulk actions on agents with unmerged worktree commits must not delete branches (P2C.3's
  rule) — surface what will be kept.
- Do not implement drag-reorder; order is frozen (P3.4).
