# P5.5 — Reasoning effort per agent, changeable mid-session
Phase: 5 · Depends on: P5.4 · Tag: autonomous · Execution-mode: medium

## Goal
Effort is the cheapest quality/cost dial there is, and it should be per-agent, not global.

## Files
- `Sources/ContinuumRevived/App/AgentSupervisor.swift`
- `Sources/ContinuumRevived/Canvas/ManagedAgentTileNSView.swift` (header picker)

## Approach
`get_available_thinking_levels` returns the valid set **for the current model** (`["off"]` when
unsupported — GPT-5.6 exposes through `xhigh`/`max`). `set_thinking_level` applies; persist on
`AgentRecord.thinking`. The picker must be driven by the returned set, never a hardcoded list, and must
re-query after a model change (P5.4) since the valid set is model-dependent.

## Done when
Effort changes mid-session, persists, and the picker reflects the current model's real options.

## Verify
**Deterministic:** fake client returning `["off"]` → the picker shows a single disabled option (witness:
offering `max` for a model that does not support it must FAIL); after a `set_model`, levels are re-queried.
**Manual:** raise effort on a live agent and confirm the next turn's reasoning behaviour changes.

## Watch out
- A `thinkingLevelChange` session entry exists — surface it like the model change, not silently.
