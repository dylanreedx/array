# P1.1 — Stand up the ContinuumRevivedAgentUI module
Phase: 1 · Depends on: none · Tag: autonomous · Execution-mode: medium

## Goal
A shared, AppKit/UIKit-free module both platforms consume, seeded from the one component that
already works this way. `ContinuumRevivedCore` is 140+ files of storage/sync/registry logic; visual
tokens do not belong there. Ticket 87's watch-out #5 sets the trigger at ~3 shared components — a
token system plus a re-homed StatusChip clears it on day one.

## Files
- `Package.swift` (new target `ContinuumRevivedAgentUI` + `ContinuumRevivedAgentUIChecks`)
- `Sources/ContinuumRevivedAgentUI/` (new; move `Sources/ContinuumRevivedCore/AgentUI/StatusChip.swift` here)
- `Sources/ContinuumRevivedAgentUIChecks/main.swift` (new; move `StatusChipChecks.swift` here)
- `ios/project.yml` (add the product dependency), then run `xcodegen generate`
- `scripts/run-matrix.sh` (register the new checks executable)

## Approach
`git mv` StatusChip.swift and StatusChipChecks.swift; do not rewrite them. The module must import
only `Foundation`. Keep `ContinuumRevivedCore` depending on nothing new — instead have
`ContinuumRevived` (app), `ContinuumRevivedAgentUIChecks`, and the iOS target depend on the new
module. If any Core file references `StatusChipPresenter`, either move that reference or have Core
depend on AgentUI (Core → AgentUI is acceptable; AgentUI → Core is NOT).

## Done when
- `swift build` green; the new checks executable runs the existing StatusChip assertions unchanged.
- iOS target builds (P0.1's matrix leg proves it).
- `grep -rn "import AppKit\|import UIKit" Sources/ContinuumRevivedAgentUI/` returns nothing.

## Verify
`./scripts/run-matrix.sh` — the moved StatusChip checks must still run and pass (same output text),
and the matrix inventory guard (P0.11) must show the leg renamed/added, not lost.

## Watch out
- `xcodegen generate` is required after touching `ios/project.yml`, or the iOS target silently won't
  see the new module.
- Do not change any StatusChip behaviour in this ticket. Pure move + wiring. Behaviour changes are
  P1.8's job.
