# P5.9 — Wire the approval dock to REAL approvals
Phase: 5 · Depends on: P5.2 · Tag: autonomous · Execution-mode: high

## Goal
`ApprovalDockView` exists, is styled, and is tested — and has never once shown a real approval, because
in json mode `ctx.hasUI == false`, so a permission-gate extension can only hard-block. This is the
ticket that makes supervised agents real.

## Files
- `Sources/ContinuumRevivedCore/AgentProviders/PiRpcClient.swift`
- `Sources/ContinuumRevived/App/AgentSupervisor.swift`
- `Sources/ContinuumRevived/Canvas/ApprovalDockView.swift` (existing; do not restyle)
- `Resources/PiExtensions/continuum-permission-gate.ts` (new)

## Approach
Two halves:
1. **Extension:** `pi.on("tool_call")` gate that calls `ctx.ui.confirm()/select()` for risky tools. In
   rpc mode `hasUI` is true, so Pi marshals it as `extension_ui_request` on stdout.
2. **Client:** on `extension_ui_request` (`confirm`/`select`/`input`), map to
   `AgentRuntimeEvent.requestOpened` → the existing dock. The user's choice returns as
   `extension_ui_response` with the matching `id`. `requestResolved` closes it.

Honour the optional agent-side `timeout` — if it elapses, Pi auto-resolves, so the dock must close and
say it timed out rather than lying that the user decided.

## Done when
A real risky tool call raises the dock, and Approve/Deny actually allows or blocks the call.

## Verify
**Deterministic:** fake client — an `extension_ui_request` becomes `requestOpened` with the right kind;
the dock's decision emits `extension_ui_response` carrying the SAME id (witness: a mismatched id must
FAIL); a timeout closes the dock as timed-out, not approved.
**Manual (required, supervised GUI):** run a live agent that tries `bash rm -rf`, approve once, deny once,
and confirm the tool actually ran / did not run.

## Watch out
- **Deny must genuinely block.** A dock that reports denial while the tool still executes is the worst
  possible outcome — assert the block path, not just the UI.
- Project trust gates *loading* project extensions and never prompts in non-interactive modes; document
  where the gate extension must live (`~/.pi/agent/extensions/`) so it loads without a trust prompt.
