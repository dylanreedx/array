# P0.7 — Retire `isBlank` as the visual gate
Phase: 0 · Depends on: P0.3, P0.4, P0.5, P0.6 · Tag: autonomous · Execution-mode: low

## Goal
The entire current visual gate is `distinctSampledColors <= 1` — "the image has more than one
colour." Black-on-dark text, half-width cards and a blank transcript all passed it. Once the real
gates exist, demote this to a smoke floor so it stops being mistaken for verification.

## Files
- `Sources/ContinuumRevived/App/ComponentLab.swift` (the per-card loop, ~:2055-2090)
- `Sources/ContinuumRevived/App/VisualSnapshot.swift`

## Approach
Keep `isBlank` (a genuinely blank render is still worth catching) but have the Component Lab check
additionally run the P0.3–P0.6 gates for every static entry, in both appearances. Replace the
hand-picked `distinctSampledColors != distinctSampledColors` delta pairs with baseline comparison,
which subsumes them. Rename the comment block so the next reader knows blankness is a floor, not
a gate.

## Done when
`--component-lab-check` runs geometry + contrast + pixel + baseline gates per entry, in both
appearances, and the ad-hoc distinct-colour delta assertions are gone (superseded, not weakened).

## Verify
`./scripts/run-matrix.sh` green. Confirm the check count did not shrink (see P0.11) and that
removing a width pin now fails the Lab check.

## Watch out
- This is the one ticket allowed to *remove* assertions, and only because the baseline compare
  strictly subsumes them. Do not remove anything else. If in doubt, keep both.
- Runtime will grow (2 appearances × N entries). Keep it under a couple of minutes; if it drags,
  probe fewer sizes, never fewer appearances.
