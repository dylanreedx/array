# P5.3 — `abort` → a real Stop button
Phase: 5 · Depends on: P5.2 · Tag: autonomous · Execution-mode: medium

## Goal
Today the only way to stop a running agent is SIGTERM to the process — there is no in-band cancel in
print mode at all. Give the tile a Stop that actually stops the turn and keeps the session alive.

## Files
- `Sources/ContinuumRevived/App/AgentSupervisor.swift`
- `Sources/ContinuumRevived/Canvas/ManagedAgentTileNSView.swift` (compose row)

## Approach
`abort` while a turn is streaming; `abort_bash` for a running command. The button replaces Run while
`working` (the compose row already latches busy via `promptInFlight`). After an abort the session must
remain usable — the next prompt continues the same conversation.

## Done when
Stop ends the current turn, the transcript shows it as interrupted, and the next prompt still works.

## Verify
**Deterministic:** fake client asserts `abort` is sent, the turn resolves as `.interrupted` (mapping to
`turnCompleted(outcome: .interrupted)`), the session stays open, and a subsequent prompt is accepted
(witness: a Stop that kills the session must FAIL).
**Manual:** interrupt a real long-running turn.

## Watch out
- Do not conflate Stop (abort the turn) with Stop agent (terminate the session, P2A.5's explicit action).
  Two different affordances; name them distinctly in the UI.
