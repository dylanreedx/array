# P3.7 — Slim row variant for settled/snoozed
Phase: 3 · Depends on: P3.6 · Tag: autonomous · Execution-mode: low

## Goal
Density comes from *parking* work, not from the list second-guessing importance. **Settled and snoozed
are the only things that collapse; every other agent is a full card.**

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach
~36pt single-line variant: dimmed glyph + title + PR/branch badge + relative time, glyph restored to
full on hover so the tail stays scannable while hunting. Driven by `AgentInboxRow.variant` (P3.1).
Key each row view by `id:variant` so a lifecycle transition crossfades in place rather than sliding
through intervening rows (translucent rows sliding read as text painted over text).

## Done when
Settled/snoozed render slim; everything else stays a card.

## Verify
Baselines for card and slim variants of the same agent; a check asserting variant follows lifecycle
and that no non-settled/snoozed row is ever slim.

## Watch out
- Do not collapse `ready` or `failed` — that is the density mistake this rule exists to prevent.
