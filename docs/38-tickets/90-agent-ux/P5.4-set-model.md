# P5.4 — Change model mid-session
Phase: 5 · Depends on: P5.2 · Tag: autonomous · Execution-mode: medium

## Goal
Switch an agent's model without losing its conversation — impossible in print mode.

## Files
- `Sources/ContinuumRevived/App/AgentSupervisor.swift`
- `Sources/ContinuumRevivedCore/AgentModelConfig.swift`

## Approach
`get_available_models` populates the picker; `set_model` applies. Persist the choice on
`AgentRecord.model` so it survives relaunch. Model ids must stay **fully qualified** (P0.10) — never
re-introduce fuzzy matching. The session records a `model_change` entry, so the transcript should show
the switch as a system-ish marker rather than silently changing behaviour.

## Done when
A running agent's model changes, persists, and the transcript notes it.

## Verify
**Deterministic:** fake client — `get_available_models` list is surfaced verbatim; `set_model` with an
unqualified id is REJECTED before sending (witness); the record persists the new id.
**Manual:** switch a live agent between two `gpt-5.6-*` variants and confirm the next turn uses it.

## Watch out
- Only `openai-codex` is authed on this machine; do not offer models whose provider has no credentials
  (`--list-models` only shows usable ones).
