# P4.8 — Settled tail paging
Phase: 4 · Depends on: P4.7 · Tag: autonomous · Execution-mode: low

## Goal
Keep history reachable without letting it dominate the list.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`
- `Sources/ContinuumRevivedAgentUI/InboxSort.swift`

## Approach
Show the first **10** settled rows, then `Show 25 more (N settled hidden)`. Settled rows sort by when
work *ended* (`settledAt`), newest first — they are history, so the frozen creation-order rule (P3.4)
does not apply to them.

**Always force-include the currently-open agent**, even if it falls outside the page — otherwise
navigating to a settled agent hides the row you are looking at.

## Done when
Paging works and the open agent is never paged out.

## Verify
Pure checks: 30 settled → 10 shown + correct hidden count; expanding adds 25; the open agent appears
even when it would be row 27 (witness).

## Watch out
- Do not apply the frozen sort to settled rows; do not apply the settled sort to active rows.
