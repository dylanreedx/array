# P4.7 — Collapsed `Snoozed (N)` shelf
Phase: 4 · Depends on: P4.6, P3.7 · Tag: autonomous · Execution-mode: low

## Goal
Deferred work is visible as a count without occupying the list.

## Files
- `Sources/ContinuumRevived/App/AgentInboxView.swift`
- `Sources/ContinuumRevivedAgentUI/InboxSort.swift` (partition)

## Approach
Three sections in order: **active** → collapsed `Snoozed (N)` → **settled tail**. The shelf is
collapsed by default (local UI state, not persisted per-agent), expanding to slim rows (P3.7). A
**woken** agent (P4.6) leaves the shelf and rejoins active — it must not stay hidden behind a
collapsed header.

Partition is pure: `partition(rows:now:) -> (active:[…], snoozed:[…], settled:[…])`, so it is testable
without a view.

## Done when
Snoozed agents collapse under a counted header; woken ones appear in active.

## Verify
Pure checks: partition is exhaustive and disjoint; a woken agent lands in `active`, not `snoozed`
(witness); the count matches the shelf contents.

## Watch out
- Do not hide a snoozed agent that has a pending approval — P4.2's blocker precedence already forces it
  active, and the partition must respect that rather than re-deciding.
