# P2.2 — Measured-fit tiers and the cell inset

Phase: 2 · Row anatomy
Execution: **autonomous**
Depends on: P2.1

## Goal

Adapt the row by comparing measured need against available width in named tiers, with the 4 pt cell inset in every measurement.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Replace every hard-coded width threshold in the sidebar with a tier chosen by comparing measured need against the width the row actually has.
2. Add the 4 pt `NSTextField` cell inset to every hand-laid-out measurement, including any guaranteed-minimum floor, so the floor itself cannot ellipsise.
3. Name the tiers and their sacrifice, e.g. full, abbreviated, caption-hidden, so a reviewer can see which tier a width lands in.
4. Assert the tier boundaries by measurement at 220, 280, and 320 pt, and assert that no tier draws a truncated name.

### Implementation sketch

```swift
private var measuredWidth: CGFloat {
    ceil((label.stringValue as NSString)
        .size(withAttributes: [.font: NSFont.token(.label)]).width) + 4  // cell inset
}
func tier(forAvailable width: CGFloat) -> RowTier { … }
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- No width threshold literal remains in the sidebar's layout path.
- Every measurement includes the cell inset; a minimum-width floor no longer ellipsises its own content.
- Tier selection is asserted at all three widths, and each tier's sacrifice is asserted rather than described.
- The name draws untruncated in every tier for every corpus fixture that can fit.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- `minimumTextWidth` currently measures the raw string with no inset, so the guaranteed minimum itself elides — the same class of bug the composer fixed.
- A tier that hides an element must still expose it to VoiceOver or drop it from the accessibility tree deliberately, not accidentally.
- Do not add a fourth tier to avoid making a sacrifice decision.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
