## Goal

Harden this program's structural guard with throwaway-copy mutation self-tests and matrix wiring before any sidebar change lands.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

relay, FileTree, provider, or cleanup work.

## Approach

1. Extend the bootstrap guard so the queue is validated against each packet's own five-line header — id, phase, execution mode, dependency line — and not merely against file presence.
2. Validate the ledger against the fixed state vocabulary, one unique row per packet, at most one in-progress row, and no forged commit or timestamp on work that has not run.
3. Add a `--self-test` mode that copies the live program into a temporary root, mutates it there, and requires this same script to go red with a named error for every failure mode it claims to catch; the live queue, ledger, and packets are never written.
4. Wire this program's leg into `scripts/run-matrix.sh` **after** queue 91's locked four-line executable prefix, and record it in the committed matrix inventory.
5. Assert the four supervised gates by id so a downgrade to autonomous is a named failure.

### Implementation sketch

```bash
required=("## Goal" "## Context and design direction" "## Files" "## Approach" \
          "### Implementation sketch" "## Done when" "## Verify" "## Watch out")
for packet in "$DIR"/P*.md; do
  for heading in "${required[@]}"; do
    grep -Fxq "$heading" "$packet" || fail "$packet missing $heading"
  done
done
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- A missing packet, duplicate id, forward or cyclic dependency, queue/packet header mismatch, invalid ledger state, forged bookkeeping, or downgraded supervised gate each fail with a named error.
- Self-test fixtures leave the live queue, ledger, and packets byte-identical.
- Queue 91's locked four-line matrix prefix is unchanged and `./scripts/check-agent-tile-ux-program.sh` is still green.
- The matrix inventory records exactly one added leg; nothing is removed or lowered.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
