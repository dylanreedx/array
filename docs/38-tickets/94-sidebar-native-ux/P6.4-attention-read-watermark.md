# P6.4 — Attention and the read watermark

Phase: 6 · Lifecycle and children
Execution: **autonomous**
Depends on: P6.3

## Goal

Track what the owner has actually seen, so unread and woke mean something and reading the inbox never reorders it.

## Approach

1. Derive unread from a completion later than the read watermark, and woke from a wake later than it, keeping the two opposite never-visited defaults: never-visited counts as read, but never-visited counts as woke.
2. Make the watermark monotonic — store the maximum — so a replayed or out-of-order visit cannot rewind it, while an explicit mark-unread rewinds it deliberately.
3. Never bump an activity timestamp when recording a visit, so reading the inbox cannot reorder it.
4. Throttle watermark writes, but let an unread-clearing write through immediately.

### Implementation sketch

```swift
// Opposite defaults on purpose: unread must not light up history; a wake must not be eaten.
var isUnread: Bool { completedAt.map { $0 > (lastVisitedAt ?? .distantFuture) } ?? false }
var isWoke: Bool   { wokeAt.map     { $0 > (lastVisitedAt ?? .distantPast) }   ?? false }
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- Never-visited rows are read but woke, asserted for both axes.
- The watermark is monotonic against replayed and out-of-order visits; mark-unread rewinds it explicitly.
- Recording a visit does not bump any timestamp the sort reads, asserted by ordering the list before and after.
- Watermark writes are throttled, and an unread-clearing write is not delayed.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- An unparseable stored timestamp must count as never-visited for the woke axis: corrupt local data must not eat the wake signal.
- If a visit bumps activity, reading your inbox reorders it — and on this program's frozen ordering that is a visible defect.
- Unread is a mark, not a word; do not add an “Unread” label.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
