# P2.1 — The name owns its own line

Phase: 2 · Row anatomy
Execution: **autonomous**
Depends on: P1.5

## Goal

Give the agent's name a full line of its own and make it the last thing that yields when width runs out.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Restructure the card into three bands: an upper meta band, the name on its own full-width line, and a lower detail band.
2. Invert the sacrifice order: the name keeps the highest compression resistance of any text on the row, and the caption, project chip, branch, and metrics yield first.
3. Record the chosen sacrifice order in a comment as a decision, not as a consequence of priorities.
4. Assert at all three widths that the name draws untruncated whenever any other element could have yielded instead.

### Implementation sketch

```swift
// Sacrifice order (decision, not emergent): caption -> project chip -> branch
// -> metrics -> name. The row's subject yields last.
nameLabel.setContentCompressionResistancePriority(.required, for: .horizontal)
projectChip.setContentCompressionResistancePriority(.defaultLow, for: .horizontal)
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- At 220 pt the name draws untruncated for every corpus fixture whose name fits a full line.
- When the name genuinely cannot fit, every other element has already yielded — asserted, not assumed.
- The sacrifice order is documented in a comment at the point it is enforced.
- Row height and hit area are unchanged by this packet.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- Today the name is the only compressible element, so it absorbs the entire deficit; simply raising its priority without lowering the others moves the failure rather than fixing it.
- Do not introduce a width threshold; measured fit is P2.2's work and this packet must not pre-empt it.
- The upper band's status slot must not blank the name when a modifier-held hint appears.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
