# P2.5 — One elapsed formatter, capped and columnar

Phase: 2 · Row anatomy
Execution: **autonomous**
Depends on: P2.4

## Goal

Give durations one shared, bounded formatter and a fixed column, so a long-running agent stops eating the name's width.

## Approach

1. Move duration formatting into one shared function used by the sidebar, the tile header, and any phone payload, replacing the divergent vocabularies.
2. Coarsen past a day and cap the rendered form, so no duration can grow without bound; clamp negative and non-finite input to zero.
3. Reserve a fixed monospaced-digit column sized for the widest form the formatter can emit, so the name's width no longer depends on how long an agent has run.
4. Assert the formatter's output for a table of inputs including zero, sub-minute, sub-hour, multi-hour, multi-day, negative, and non-finite.

### Implementation sketch

```swift
static func elapsedLabel(_ seconds: TimeInterval) -> String {
    guard seconds.isFinite else { return "0s" }
    let s = max(0, Int(seconds))
    if s < 60 { return "\(s)s" }
    if s < 3_600 { return "\(s / 60)m" }
    if s < 86_400 { return "\(s / 3_600)h \((s % 3_600) / 60)m" }
    return "\(s / 86_400)d"
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- One function formats durations for every surface; no second vocabulary remains.
- Negative and non-finite input render as zero, asserted.
- The elapsed column is fixed-width for the widest emittable form, and the name's drawn width no longer varies with duration.
- The tile header and the sidebar render the same duration identically.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- The tile header currently renders the same duration as minutes-plus-seconds while the sidebar renders hours; unifying them changes the header, which is why it is in the fence.
- A cap that hides real information is wrong; coarsen the unit rather than clipping the number.
- Anchoring is Phase 3's work — this packet fixes the format and the column, not where the clock starts.
