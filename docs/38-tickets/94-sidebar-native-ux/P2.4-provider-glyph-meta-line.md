# P2.4 — Model as a glyph, and a meta line worth its space

Phase: 2 · Row anatomy
Execution: **autonomous**
Depends on: P2.3

## Goal

Stop printing a model id twice per row: render the provider as a quiet glyph and give the lower band facts a human needs.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and

## Approach

1. Render the provider as a small greyscale glyph in the lower band, with the full model available to VoiceOver and to hover help, never as the row's title.
2. Rebuild the subtitle so it no longer repeats the name: branch when present, then isolation, then remote, then the provider glyph.
3. Drop any element that carries no information for the row it is on, rather than rendering an empty slot that reserves width.
4. Assert that no row draws the same string twice and that the model id never appears in the name position.

### Implementation sketch

```swift
// The model is metadata: a glyph plus accessibility, never the row's subject.
providerGlyph.image = ProviderGlyph.image(for: row.model)
providerGlyph.setAccessibilityLabel(row.model)
subtitle.stringValue = [row.branch, row.isolationLabel].compactMap { $0 }.joined(separator: " · ")
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- No row renders the same string in two places, asserted over the live tree.
- The model id never occupies the name position for any corpus fixture.
- An absent branch or role removes its element rather than reserving width for it.
- The provider glyph carries an accessibility label naming the model.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
