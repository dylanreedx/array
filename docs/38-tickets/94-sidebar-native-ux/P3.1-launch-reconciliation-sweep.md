# P3.1 — Launch reconciliation sweep

Phase: 3 · Status truthfulness
Execution: **autonomous**
Depends on: P0.3

## Goal

At launch, terminalize every persisted agent whose recorded status is non-terminal, with a stated reason, so a record on disk can never assert liveness.

## Approach

1. Add one sweep that runs before any surface reads agent state: every persisted record whose status is non-terminal becomes terminal, with a reason string naming the restart.
2. Fix the writer as well as the reader: the spawn-time record must not be able to say `starting` forever, and records already on disk must migrate rather than being reinterpreted.
3. Keep system-cancel and user-stop as distinct recorded values, so a later reader can tell “the app killed this” from “I killed this”.
4. Make the sweep idempotent, run the identical path on graceful shutdown with a different reason, and assert both.

### Implementation sketch

```swift
// A record proves something happened, never that something is happening.
for var record in store.nonTerminalRecords() {
    record.status = .cancelled
    record.endedReason = "Cancelled because Continuum restarted before the agent's work completed."
    store.write(record)
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- After a simulated restart, no persisted agent reports a non-terminal status.
- The reason string is recorded and reachable by the UI, not merely logged.
- Running the sweep twice changes nothing the second time.
- A record written by the old spawn path is migrated, not reinterpreted, and the migration is asserted.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
