# P1.1 — Remove the row perimeter border

Phase: 1 · Containment and surface
Execution: **autonomous**
Depends on: P0.4, P0.5

## Goal

Stop painting a grey box around every idle row.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

- `Sources/ContinuumRevived/App/AgentInboxView.swift`

## Approach

1. Set the row card's painted border width to zero and drop its opaque resting fill, so a row at rest paints no perimeter and no background.
2. Keep the corner radius, insets, and hit area unchanged; this packet changes paint, not geometry.
3. Assert structurally over the live view tree that no row cell view paints a perimeter border in any state, in both appearances, so a reintroduction fails the same assertion the removal satisfied.
4. Re-measure the appearance census floors in the same change, with the reason recorded in a comment next to each number.

### Implementation sketch

```swift
// Rows never paint a perimeter: state is fill plus content (see _DESIGN.md).
layer?.borderWidth = 0
layer?.backgroundColor = nil
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- Every row state paints zero border width in both appearances, asserted over the live tree.
- The resting row shows the sidebar's own surface, not an opaque card fill.
- `minimumThemedViews` and `minimumSentineledSlots` are re-measured in this change with the reason in a comment.
- Row geometry, insets, and hit testing are unchanged from the pre-change measurements.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
