# P4.1 — A sentinel name, and never an identifier

Phase: 4 · Identity and naming
Execution: **autonomous**
Depends on: P3.6

## Goal

Give every agent a displayable human name from one shared constant, and make rendering an identifier as a name impossible.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and

## Approach

1. Introduce one shared default-name constant and seed `displayName` from it instead of `role ?? model`, so a nameless agent is born displayable.
2. Treat the sentinel as the only permission slip a later packet may use to overwrite a name automatically.
3. Add a defensive read so a persisted name that is a model id, role id, or UUID renders as the sentinel plus metadata rather than as a title.
4. Migrate records already on disk whose name is an identifier, and assert the migration.

### Implementation sketch

```swift
static let defaultAgentName = "New agent"   // one constant, one place
displayName = AgentRecord.defaultAgentName    // never `role ?? model`
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- No spawn path can produce a name equal to a model id, role id, or UUID.
- The sentinel lives in exactly one place; a second literal fails a named assertion.
- A persisted identifier-shaped name renders as the sentinel plus metadata, and existing records are migrated.
- The clobber check that incidentally pinned `displayName == config.model` is updated rather than deleted.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- `AgentSupervisor` has a clobber check that pins `displayName == config.model`; changing the seed without updating it breaks an unrelated assertion.
- Five divergent copies of a sentinel literal is how the reference implementation silently disabled its own naming; one constant only.
- Do not generate a name here; P4.2 owns seeding and P4.5 owns generation.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
