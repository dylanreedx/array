# P1.3 — Headers, shelves, and the last 1 pt literals

Phase: 1 · Containment and surface
Execution: **autonomous**
Depends on: P1.2

## Goal

Bring the sidebar's remaining containment — section headers, shelf toggles, and every stray 1 pt literal — onto the shared hairline token.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Replace every 1 pt literal line in the sidebar with the P0.5 hairline token; a separator is a decorative hairline, not a control boundary.
2. Give section and shelf headers a quiet treatment: a label, an optional count, a flexible hairline, and a disclosure affordance — no boxed container.
3. Keep exactly one boundary per surface; no nested boxes, and no panel border plus row borders.
4. Assert by measurement that no sidebar line exceeds the hairline token's width.

### Implementation sketch

```swift
// One boundary per surface. A separator is decorative; a control edge is not.
separator.layer?.backgroundColor = AgentLineRole.decorativeHairline.color.cgColor(for: theme)
separator.heightAnchor.constraint(equalToConstant: SidebarMetrics.hairline).isActive = true
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- No sidebar line paints wider than the hairline token, asserted over the live tree at all three widths.
- Shelf and section headers paint no container box.
- No surface paints two nested boundaries.
- Decorative separators use the decorative role; interactive edges use the control-boundary role.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
