# P1.4 — Focus ring, keyboard-visible selection, and re-measured floors

Phase: 1 · Containment and surface
Execution: **autonomous**
Depends on: P1.3

## Goal

Make keyboard focus and selection unmistakable without a permanent border, and leave every appearance floor honestly re-measured.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved

never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Give the focused row a temporary focus treatment from `AgentLineRole.focusRing` at hairline width with a soft glow — never a permanent grey outline, never the default AppKit ring.
2. Make keyboard focus and mouse selection independently visible, so a keyboard user can tell which row will act on Return.
3. Verify contrast for focus, selection, and their combination in both appearances, and re-measure the pixel and appearance floors this phase moved.
4. Record each re-measured floor's new value with the reason in a comment beside it.

### Implementation sketch

```swift
// Focus is temporary and legible; selection is a resting fill.
focusRing.isHidden = !hasKeyboardFocus
focusRing.layer?.borderWidth = SidebarMetrics.hairline
focusRing.layer?.borderColor = AgentLineRole.focusRing.color.cgColor(for: theme)
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- A keyboard-focused row is distinguishable from a merely selected row, and both from resting, in both appearances.
- The focus treatment disappears when focus leaves; nothing permanent remains.
- No default AppKit focus ring is drawn anywhere in the sidebar.
- Every floor this phase moved is re-measured in this packet with its reason in a comment.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.
