# P5.4 — Keyboard traversal and jump hints

Phase: 5 · Native interaction
Execution: **autonomous**
Depends on: P5.3

## Goal

Make the sidebar fully drivable from the keyboard, with modifier-held jump hints that never move anything.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Implement full traversal: arrow keys, Home and End, page keys, type-select, Return to open, Space to preview, and shift or command click parity from the keyboard, with the focused row always scrolled into view.
2. Add modifier-held jump hints as an overlay that returns nil from hit testing, so it neither displaces the status label nor shifts any layout when it appears.
3. Cap the hints at nine, index them against only the rows actually rendered, and show them only when the held modifier set exactly matches a jump binding.
4. Gate global shortcuts on focus context, so a shortcut does not fire while a rename field or a search field is being typed into.

### Implementation sketch

```swift
// The hint is an overlay: no layout participation, no hit testing.
override func hitTest(_ point: NSPoint) -> NSView? { nil }
guard heldModifiers == jumpBinding.modifiers, index < 9 else { return }
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- Every listed key works, and the focused row is always scrolled into view.
- Showing a jump hint changes no other element's frame, asserted before and after.
- Hints are capped at nine and indexed against rendered rows only; a collapsed shelf consumes no slot.
- A shortcut does not fire while a rename or search field has focus.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- An inline hint slot blanks the status label when the modifier is held — that is precisely why it must be an overlay.
- Hints that index against the full model rather than the rendered rows point at the wrong agent once a shelf is collapsed.
- A hint that swallows clicks intended for a lifecycle button is worse than no hint.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
