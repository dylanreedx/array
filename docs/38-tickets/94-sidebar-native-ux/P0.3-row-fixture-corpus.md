Phase: 0 · Foundations

## Goal

Replace a fixture set that cannot fail with one carrying every shape this program exists to fix.

## Context and design direction

Read `_DESIGN.md` and `_RUNBOOK.md` before editing, plus
`docs/38-tickets/91-agent-tile-ux/plan-sidebar-t3code-study.md` and
`plan-sidebar-and-state-findings.md` for the evidence this program is built on. Surface is reserved
for interaction; the row's subject is its name; one owner answers what an agent is doing; a name is
never an identifier; no stock AppKit chrome belongs in the sidebar. Every geometry assertion runs at
220, 280, and 320 pt. This ticket is deliberately scoped so another fresh agent can verify and
commit it independently.

## Approach

1. Add fixtures for: a title equal to a fully qualified `provider/model` id; nil role with nil branch; a three-digit-hour elapsed; an agent with no live snapshot; a forty-child fan-out under one parent; a project name wider than the row; and a name carrying combining marks plus a right-to-left run.
2. Declare the corpus once and gate declaration/usage parity in both directions, so an added fixture nobody renders and a rendered fixture nobody declared are both red.
3. Gate coverage: every `InboxState`, every `InboxAttention`, every `InboxLifecycle`, both `RowVariant` values, and depths 0, 1, and 2 each appear at least once.
4. Run an I5 hygiene scan over the corpus: no real home path, host name, user name, key material, or secret shape.

### Implementation sketch

```swift
enum SidebarRowFixture: String, CaseIterable {
    case titleIsModelId        // "openai-codex/gpt-5.6-sol" as a NAME
    case nilRoleNilBranch      // the two-empty-lines dead-space row
    case elapsedThreeDigitHour // 162h21m
    case unobservedNoSnapshot  // disk-derived, never confirmed
    case fanOutFortyChildren   // one parent, forty depth-1 rows
}
```

The sketch establishes ownership and direction; adapt names to the compiled code, but do not replace
the architecture with a shortcut that couples derivation, presentation, and persistence.

## Done when

- Every listed shape exists as a declared fixture and is rendered by at least one check leg.
- Coverage assertions fail when a state, attention value, lifecycle, variant, or depth loses its fixture.
- The hygiene scan fails on a planted home path and on a planted key-shaped string.
- No fixture text is captured from a real session.
- Relevant new behavior has a deterministic positive assertion and at least one required negative
  witness observed red against the final check.
- No existing matrix leg, assertion floor, contrast requirement, or I5 boundary is weakened.

## Watch out

- A corpus whose maximum elapsed is two hours cannot fail the elapsed packet; a corpus with roles and branches present cannot fail the dead-space packet.
- Fixtures are written, not captured — do not paste a real transcript, path, or agent name.
- Do not weaken the parity gate to accommodate a fixture that is convenient to render ad hoc.
- Never stage, commit, push, rebase, or alter queue/loop machinery outside the per-ticket workflow.
- If the packet conflicts with compiled reality or a locked decision, mark it `blocked` with concrete
  evidence; do not improvise a second architecture.
