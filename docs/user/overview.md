Array puts coding agents, terminals, documents, browsers, and task boards on one canvas. Keep a plan beside the agent implementing it, watch a local preview, and review the resulting changes without losing the rest of the work.

A **tile** is one surface: an agent, terminal, browser, editor, or board. A **zone** groups tiles in a named region. A **project** points at a folder on your Mac. A **workspace** brings zones and projects together into a spatial layout.

## Your first useful workspace

1. [Install Array and connect a CLI](/docs/install/). Provider sign-in happens in that CLI’s own flow.
2. Open the **Command Center** with **⌘K** and create an agent for your project.
3. Give it a bounded task: “Read this project and explain how to run it. Do not edit anything yet.”
4. Open the relevant files and a terminal beside the conversation.
5. Add a board when you need to track several tasks, and a browser when there is something to preview.

## Learn by surface or by task

The [tile guide](/docs/tiles/) covers every tile kind, including specialized surfaces you may only encounter through a workflow. [Everyday workflows](/docs/workflows/) connect those pieces into useful routines.

For the implementation, read [how CLI connections work](/docs/cli-connections/) and [how agents discover canvas tools](/docs/canvas-tools/#how-agents-know-the-tools-exist). You do not need to configure MCP manually to use Array’s managed-agent integration.

## Alpha expectations

Array is evolving. Availability depends on the app version, installed CLI, selected harness, and project state. A feature shown in the website’s demonstration does not establish that it is enabled in your install. Use the app’s live commands, model list, and disabled-action reasons as the authority.

These docs describe the checked-in application. Provider policy references were checked on October 16, 2026.
