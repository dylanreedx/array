Array Companion, an iPhone app for following your agents away from the Mac, is coming soon. It is not available yet.

## What you may see today

The Mac app has an **iPhone** pane in Settings. It belongs to the upcoming Companion and has nothing you need to set up now. Array works fully on the Mac without it.

When the Companion is ready, it will be announced on [arrayapp.dev](https://arrayapp.dev/) and in the release notes.
