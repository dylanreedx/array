## What is broken
- The repository had in-process QA flows but no external cliclick and osascript harness for stress interactions that need real macOS input and window control. Sources/ContinuumRevived/App/ContinuumApp.swift:853

## Why
- The existing capture helper only runs inside the AppKit process when `CONTINUUM_QA_CAPTURE` is set, so it cannot independently spam Cmd-K, drag past screen edges, resize the OS window, or quit during browser load. Sources/ContinuumRevived/App/QACapture.swift:24
- Named smoke flows close themselves through the shared QA finish path, which makes them useful for deterministic in-process captures but not enough for longer external driver actions. Sources/ContinuumRevived/App/ContinuumApp.swift:1274
