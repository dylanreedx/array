## What is broken
- Cmd-K could spawn notes and file tiles, but it had no `Open File Tree...` action row for the current project root. Sources/ContinuumRevivedCore/LaunchPaletteModel.swift:87 Sources/ContinuumRevived/App/ContinuumApp.swift:529.
- File-tree rows could open or spawn a file tile by activation, but dragging a file row to empty canvas space had no pasteboard source and no canvas drop route to `spawnFile`. Sources/ContinuumRevived/Canvas/FileTreeTileNSView.swift:134 Sources/ContinuumRevived/Canvas/CanvasNSView.swift:23.

## Why
- The Core launch palette action enum only modeled `newNote` and `openFile`, so the AppKit palette switch had no file-tree case to dispatch. Sources/ContinuumRevivedCore/LaunchPaletteModel.swift:3 Sources/ContinuumRevived/App/ContinuumApp.swift:529.
- The outline view was configured for selection, activation, and context menu actions, while the canvas only accepted pan, zoom, mouse, and tile-management events. Sources/ContinuumRevived/Canvas/FileTreeTileNSView.swift:177 Sources/ContinuumRevived/Canvas/CanvasNSView.swift:148.

## Fix
- Added `LaunchPaletteAction.openFileTree`, appended it after `Open File...`, and made tree-specific queries isolate `Open File Tree...` while broad `open file` queries still list both file actions. Sources/ContinuumRevivedCore/LaunchPaletteModel.swift:6 Sources/ContinuumRevivedCore/LaunchPaletteModel.swift:78 Sources/ContinuumRevivedCore/LaunchPaletteModel.swift:91.
- AppDelegate now routes the file-tree palette action to `spawner.spawnFileTree(rootPath: project.rootPath)`. Sources/ContinuumRevived/App/ContinuumApp.swift:535 Sources/ContinuumRevived/App/ContinuumApp.swift:578.
- File-tree outline rows now write file URL pasteboard items for non-directory rows and advertise copy dragging. Sources/ContinuumRevived/Canvas/FileTreeTileNSView.swift:86 Sources/ContinuumRevived/Canvas/FileTreeTileNSView.swift:182.
- Canvas file URL drops now convert the drop point through `CanvasEngine.screenToWorld`, and TileSpawner wires that drop to `spawnFile(path:at:)`. Sources/ContinuumRevived/Canvas/CanvasNSView.swift:187 Sources/ContinuumRevived/App/TileSpawner.swift:61.
