## What is broken
- The file tree tile design needed persisted Core state for roots, expansion, selection, search, ignores, and git badge mode, but the Core model had no FileTreeState family before this change. docs/superpowers/specs/2026-05-09-file-tree-tile-design.md:15
- The canvas tile kind enum did not include fileTree, so canvas JSON could not represent the file-tree tile described by the design. Sources/ContinuumRevivedCore/CanvasState.swift:67
- ProjectStore had browser and note persistence paths but no .continuum-revived/file-tree/index.json path for file-tree state. Sources/ContinuumRevivedCore/ProjectStore.swift:31

## Why
- The file tree was intentionally deferred after note and single-file tiles, leaving Phase 6 without the Core-owned state shape needed for the follow-on implementation. docs/superpowers/specs/2026-05-09-file-tree-tile-design.md:9
- The file-tree state belongs in Core because root path, expanded paths, selected path, search query, ignore settings, and badge mode are project state rather than transient AppKit view state. docs/superpowers/specs/2026-05-09-file-tree-tile-design.md:15
- RuntimeRefKind does not need a fileTree case because this task persists descriptor state but does not introduce a process runtime for file trees. Sources/ContinuumRevivedCore/CanvasState.swift:88

## Fix
- Added pure Foundation FileTreeState, FileTreeTile, FileTreeNode, FileTreeGitBadgeMode, and FileTreeGitStatus types with Codable, Equatable, and Sendable conformance. Sources/ContinuumRevivedCore/FileTreeState.swift:1
- Added TileKind.fileTree and Core sizing defaults for file-tree tiles so existing canvas geometry switches remain exhaustive. Sources/ContinuumRevivedCore/CanvasState.swift:72
- Added ProjectStore file-tree layout and AtomicWriter-backed save, load, and try-load methods under .continuum-revived/file-tree/index.json. Sources/ContinuumRevivedCore/ProjectStore.swift:39
- Added boot-loop placeholder installation and smoke fixture coverage for descriptor-only file-tree tiles while leaving scanner and AppKit tree UI for later tasks. Sources/ContinuumRevived/App/ContinuumApp.swift:153
