## What is broken
- `CONTINUUM_QA_FLOW` only named the capture manifest, so `palette-open-close` and every other requested named flow still ran the monolithic default smoke timeline instead of a flow-specific user-visible sequence. Sources/ContinuumRevived/App/ContinuumApp.swift:864
- The single timeline captured default terminal, browser, note, file, resize, scroll, and canvas actions, but it had no dispatcher or per-flow helpers for palette, command, browser-error, canvas-edge, empty-canvas, or restart-placeholder surfaces. Sources/ContinuumRevived/App/ContinuumApp.swift:903

## Why
- The flow name was parsed inside `QACapture`, which affected only the manifest `flow` field and did not select which smoke actions were scheduled. Sources/ContinuumRevived/App/QACapture.swift:39
- The app target is the correct layer because the named flows drive live AppKit windows, palette state, tile spawning, Ghostty runtimes, WKWebView runtimes, and canvas viewport mutations that are not available in ContinuumRevivedCore. Sources/ContinuumRevived/App/ContinuumApp.swift:875

## Fix
- `runSmokeTest` now maps `CONTINUUM_QA_FLOW` to a typed `QASmokeFlow`, rejects unknown flow names with exit code 2, and dispatches `default-smoke` to the existing long regression timeline. Sources/ContinuumRevived/App/ContinuumApp.swift:849
- Added named helpers for palette-open-close, cmd-1-claude, cmd-2-shell, cmd-3-browser, cmd-4-nvim, terminal-mid-exit, browser-load-error, canvas-drag-resize, canvas-zoom-pan-edge, empty-canvas, and restart-placeholder-click. Sources/ContinuumRevived/App/ContinuumApp.swift:1285
- Shared QA capture and close helpers write deterministic step names, manifest data, final exit codes, and app-window PNG evidence while keeping ContinuumRevivedCore free of AppKit, WebKit, GhosttyKit, and NSWorkspace dependencies. Sources/ContinuumRevived/App/ContinuumApp.swift:1248

## Gotchas
- Similar omissions can recur if future smoke actions add only a `QACapture` manifest label instead of a `QASmokeFlow` case and dispatch branch. Sources/ContinuumRevived/App/ContinuumApp.swift:849
- The domain knowledge gap is that command-profile flows must use the TileSpawner seam directly, because calling the user hotkey path can show modal missing-command alerts that would block headless QA runs. Sources/ContinuumRevived/App/ContinuumApp.swift:1323
- The rejected alternative was to keep one timeline and add conditional capture names inside it, but that would still make short focused review flows wait for unrelated terminal, browser, note, file, and persistence assertions. Sources/ContinuumRevived/App/ContinuumApp.swift:903
