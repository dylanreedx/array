## What is broken
- The smoke test only proved restored note tiles and had no file tile gate in its success conjunction. Sources/ContinuumRevived/App/ContinuumApp.swift:1142
- The note body was being written during `runSmokeTest`, which runs after the canvas boot loop has already installed tile views. Sources/ContinuumRevived/App/ContinuumApp.swift:1075

## Why
- Note and file fixtures must exist before `tryLoadCanvas()` so the boot loop can install `NoteTileNSView` and `FileTileNSView` from canvas descriptors. Sources/ContinuumRevived/App/ContinuumApp.swift:82
- The canvas view is constructed after the smoke seed is merged, so seeding after that point cannot prove launch-time restoration. Sources/ContinuumRevived/App/ContinuumApp.swift:103

## Fix
- The launch path now calls `seedSmokeTestTiles(in:projectRoot:)` before `tryLoadCanvas()` and merges the fixed smoke note and file tiles into `canvasState` before `CanvasNSView` is constructed. Sources/ContinuumRevived/App/ContinuumApp.swift:82
- The seed helper writes `smoke-note-ok`, the fixed `NoteState` tile link, and `.continuum-revived/smoke-file.txt` before returning fixed note and file descriptors. Sources/ContinuumRevived/App/ContinuumApp.swift:764
- The final smoke assertion now checks the seeded `NoteTileNSView`, checks the seeded `FileTileNSView`, includes `fileOk`, and prints `+ note + file` only when both pass. Sources/ContinuumRevived/App/ContinuumApp.swift:1075

## Gotchas
- Similar launch-order bugs can occur anywhere a smoke fixture is created inside `runSmokeTest` instead of before canvas restoration. Sources/ContinuumRevived/App/ContinuumApp.swift:82
- The domain constraint is that descriptor data must be present before the boot loop walks `canvasState.tiles`, otherwise the display layer never sees the note or file tile to install. Sources/ContinuumRevived/App/ContinuumApp.swift:126
- The rejected alternative was to spawn file and note tiles from `runSmokeTest`, but that would test late spawning instead of persisted launch restoration. Sources/ContinuumRevived/App/ContinuumApp.swift:1075
