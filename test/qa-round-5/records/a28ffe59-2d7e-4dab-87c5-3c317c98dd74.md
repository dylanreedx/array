## What is broken
- The Cmd-K leak check was warmed before baseline sampling, so the perf gate no longer measured a cold open/close palette cycle. Sources/ContinuumRevived/App/ContinuumApp.swift:1530
- The palette used a separate NSPanel and NSSearchField allocation path for every measured open, which kept the cold `palette-leak-delta` above the 5242880 byte baseline. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:63
- The prior closure left no structural guard that palette close severs search, table, and owner references before the next QA pass. scripts/check-qa-flows.js:32

## Why
- Profile resolution is not the leak source because a diagnostic run that called `annotatedProfiles()` 25 times recorded only 16384 bytes of `palette-leak-delta`. Sources/ContinuumRevived/App/TileSpawner.swift:58
- The AppKit window/control path was the leak source because replacing only the NSPanel with an in-window palette reduced the cold delta from about 41189376 bytes to 8568832 bytes. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:63
- NSSearchField carried the remaining allocation overhead because switching the in-window filter field to NSTextField reduced the cold delta to 4849664 bytes. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:72

## Fix
- `LaunchProfilePalette` now renders as a bounded in-window view instead of a separate NSPanel, so the Cmd-K flow avoids constructing a floating panel graph during the measured cycle. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:63
- `LaunchProfilePalette.close()` now clears the search delegate, table data source, table delegate, target, view hierarchy, row arrays, and owner callback path before releasing the palette. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:41
- `AppDelegate` now creates the palette on demand and clears `profilePalette` through an `onClose` callback when the active palette closes. Sources/ContinuumRevived/App/ContinuumApp.swift:436
- `palette-leak-check` now samples the cold 25-cycle open/close path directly, with no `palette-leak-warmup` step before the resident memory baseline. Sources/ContinuumRevived/App/ContinuumApp.swift:1530
- The QA structural gate now fails if the warmup marker returns or if the palette lifetime cleanup markers disappear. scripts/check-qa-flows.js:32

## Gotchas
- A similar lifetime issue can recur in any AppKit helper that installs itself as delegate, data source, or target and is also cached by AppDelegate after close. Sources/ContinuumRevived/App/LaunchProfilePalette.swift:45
