## What is broken
- The smoke harness had no `CONTINUUM_QA_CAPTURE` or `CONTINUUM_QA_FLOW` handling, so a QA run could complete without writing `manifest.json` or any app-window PNG evidence. Sources/ContinuumRevived/App/ContinuumApp.swift:849
- The existing smoke timeline exercised text, key, scroll, resize, canvas, browser, note, and file paths, but none of those timed steps produced reusable capture artifacts for QA review. Sources/ContinuumRevived/App/ContinuumApp.swift:861

## Why
- Capture belongs in the app target because the required screenshot input is an `NSWindow` and a window number from the live smoke run. Sources/ContinuumRevived/App/QACapture.swift:100
- The seam must stay opt-in because ordinary `CONTINUUM_SMOKE_TEST=1` runs are regression gates and should not create QA files unless `CONTINUUM_QA_CAPTURE` is present. Sources/ContinuumRevived/App/QACapture.swift:28

## Fix
- Added `QACapture` with opt-in environment initialization, default `default-smoke` flow naming, ordered manifest entries, best-effort PNG writing, and non-fatal stderr logging for capture/write failures. Sources/ContinuumRevived/App/QACapture.swift:28
- Wired the smoke timeline to capture `echo-text`, `up-arrow`, `enter-recall`, `seq-scroll`, `mid-exit-trigger`, `post-exit-swap`, `resize`, `pre-scroll`, `pan-and-drag`, and `final-state` entries. Sources/ContinuumRevived/App/ContinuumApp.swift:850
- The final smoke block writes `manifest.json` after the final-state capture and before the existing production close path runs. Sources/ContinuumRevived/App/ContinuumApp.swift:1185

## Gotchas
- Similar timeline capture omissions can happen when new smoke actions are added without a nearby capture call, so future additions should update the required step list beside the scheduled action. Sources/ContinuumRevived/App/ContinuumApp.swift:861
- The domain knowledge gap is that screenshot capture is a live AppKit concern, while fixture parsing and canvas models live below the app layer and do not have an `NSWindow` to capture. Sources/ContinuumRevived/App/QACapture.swift:100
- The rejected alternative was to make QA capture mandatory for every smoke run, but that would change the default regression harness and create files when `CONTINUUM_QA_CAPTURE` is unset. Sources/ContinuumRevived/App/QACapture.swift:32
