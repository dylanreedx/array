## What is broken
- `GhosttyTerminalView` forwarded keyDown and keyUp through `ghostty_surface_key`, but it had no flagsChanged override for modifier-only AppKit events. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:52
- The default smoke test did not synthesize a modifier-only event, so the regression harness could pass without exercising Caps-to-Esc style modifier transitions. Sources/ContinuumRevived/App/ContinuumApp.swift:1031

## Why
- Modifier-only events arrive through AppKit's flagsChanged path instead of keyDown or keyUp, so the existing key event bridge never saw a modifier press or release by itself. ghostty-src/macos/Sources/Ghostty/SurfaceView_AppKit.swift:1363
- AppKit raises if a flagsChanged event is treated like a text key event, so modifier-only forwarding must avoid reading `characters` while still sending keycode and mods. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:89

## Fix
- `GhosttyTerminalView` now stores previous modifier flags, diffs them during flagsChanged, maps recognized modifier key codes, and sends press or release actions through the shared `sendKey` path. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:60
- `sendKey` now limits text extraction to keyDown and keyUp events, so flagsChanged events still reach `ghostty_surface_key` without asking AppKit for invalid text data. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:98
- `GhosttyTerminalRuntime` exposes a smoke-only dispatch helper that synthesizes flagsChanged events for the attached terminal view. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalRuntime.swift:137
- The default smoke test now sends shift, control, option, command, caps lock, repeated-state, and unknown-key flagsChanged events near the scroll check and fails unless the runtime remains running afterward. Sources/ContinuumRevived/App/ContinuumApp.swift:1035

## Gotchas
- Similar omissions can happen for any AppKit responder method that bypasses keyDown and keyUp while still needing to reach Ghostty's C input API. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:52
- The domain knowledge gap is that flagsChanged is a key event without safe text characters, so the bridge must send keycode and modifier bits without invoking `event.characters`. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:98
- The rejected alternative was to convert modifier changes into text input via `sendText`, because Ghostty's modifier semantics live in `ghostty_surface_key` and its `mods` field. Sources/ContinuumRevived/TerminalEngine/GhosttyTerminalView.swift:80
