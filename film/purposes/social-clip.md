# Purpose: social clip

A short standalone clip for a feed. It must work muted, from the first frame,
with no context around it.

This file holds questions only. The format and the look are separate choices,
and they start fresh (README.md).

## Brief questions

1. Which feed: X, LinkedIn, Instagram, TikTok? What length does it reward?
2. Which aspect: 16:9, 1:1, 9:16? Does it need all three from one edit?
3. What stops the scroll in the first second?
4. What is the single idea? If it needs two, it is two clips.
5. What must read with the sound off, at phone size?
6. Should it loop (last frame matching the first)?
7. What is the caption or post text that goes with it?
8. Does it point anywhere (link, handle, URL), and where on screen?
