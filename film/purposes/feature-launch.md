# Purpose: feature launch

Announces one new feature in a release. Success is that existing users try it
and new viewers see a reason to install.

This file holds questions only. The format and the look are separate choices,
and they start fresh (README.md).

## Brief questions

1. Which feature, in which release (version and build)? Is it merged and shipped, not just on a bench?
2. What could a user not do before, and what can they do now?
3. What is the shortest real sequence that shows it working?
4. What is the feature's real name in the UI, and which labels appear on screen?
5. Who cares most: current users or newcomers? What do they need to know first?
6. Where does it run: release notes, X, the changelog page, in-app?
7. How long, and in which aspects?
8. What must read with the sound off?
9. Does the recorder need a new scene, and does the feature behave the same in a recorded take?
10. What is the call to action: update, try it, read the docs?
