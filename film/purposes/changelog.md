# Purpose: changelog

A short visual note for one release: what changed, shown rather than listed.

This file holds questions only. The format and the look are separate choices,
and they start fresh (README.md).

## Brief questions

1. Which release, and which changes are worth showing (not every fix)?
2. How many items, and how long does each one get?
3. For each item: what did it look like before, and what does it look like now? Can both be filmed?
4. Where does it run: the appcast notes, the site, X?
5. What must read with the sound off?
6. Are the labels and numbers on screen exactly the release's (version, build, names)?
7. How does it end: the version, a download link, the next release?
