# Look: paper grid (PILOT ONLY)

Never built in the harness. It appeared in the 2026-10-15 artifact pilot of
the "three recipes, then start here" idea (formats/recipes.md, research/20
idea 4). Dylan rejected every artifact pilot ("they all look horrible...
cheesy, not the motion I'm looking for"), and artifacts are no longer used
for film (PROCESS.md). The rejection was of the pilots' execution, not
clearly of this palette.
