# Format: board story

Built: `videos/board-story` ("Hand it to an agent", r1, 2026-10-04): the first
film made from real app footage.

One task's life, told in short real takes, each cut on the bar: from the
board, to an agent, to the work, to done. Each take shows one thing and gets
one caption.

## Beats (120 BPM, a bar = 2 s; seven takes plus the lockup)

| Beat | Bars | Take | Caption |
| --- | --- | --- | --- |
| Wide | 2.5 | A glide over the canvas and its zones | "All your agents. One canvas." then "Every project gets a zone." |
| Assign | 2.5 | Drag a task card onto an agent, then send | "Drag a task onto an agent." then "It works in its own tile." |
| Edit | 2 | The agent's code opens beside it | "Its files and code sit right beside it." |
| Tests | 2 | The tests run in a real terminal | "Tests run in a real terminal." |
| Site | 1.25 | The app, live in a browser tile | "Your app, live, next to the work." |
| Needs you | 2.5 | It needs you, and you spot it | "Amber means it needs you." |
| Done | 2.5 | Green, the card moves to Done, then pull back wide | "Green is done." then "Every agent, in view." |
| Lockup | 2 | Mark, promise, URL | "Keep every agent in view." |

## What makes it work, and what didn't

- Real product features on real footage ("Impressive, actually", 2026-10-04).
- Didn't work: it felt too slow and atmospheric, and the bottom caption band
  pulled the eyes away from the action.
- Truth: real Claude Code agents never show Allow/Deny buttons, so don't
  build an approval beat on them.
