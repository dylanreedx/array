# Format: three recipes, then start here (UNBUILT)

Status: an idea, never built. Source: research/20 idea 4 (2026-10-15). It
answers Dylan's "friends don't know where to start".

Three short recipes, each a real clip in a frame with a giant number
(`01 SHIP A FEATURE`, `02 RACE THREE AGENTS`, `03 REVIEW WHILE IT WORKS`).
Then START HERE: a marker annotation circles the canvas toolbar, one click,
an agent tile appears, and the first prompt is typed. End card: "Add your
first agent."

## Beats (about 35 s, as proposed)

| Beat | Time | What happens |
| --- | --- | --- |
| Recipe 1 | about 6 s | A real clip, numbered |
| Recipe 2 | about 6 s | A real clip, numbered |
| Recipe 3 | about 6 s | A real clip, numbered |
| Start here | about 10 s | The toolbar, one click, the first agent |
| End | about 5 s | The named first action |
