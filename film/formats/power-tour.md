# Format: power tour

Built: `videos/power-tour` ("A power user's tour", accepted 2026-10-05 as
"our first video").

A single continuous real take, seen from a power user's hands. The user's
cursor is on screen and drives everything: panning, dragging, clicking. The
narration is first person, pinned to the tile it is about. Only a line about
the cursor itself rides with the cursor.

## Beats (one take, 120 BPM; lines sit on marks the recorder logged)

| Beat | What happens | Line |
| --- | --- | --- |
| Hook | The board: one fix to ship | "Let's ship one fix." (pinned to the board) |
| Grab | Drag the ticket onto an agent | "Drop it on an agent." (on the cursor) |
| Status | The sidebar row lights up | "Status, at a glance." (pinned to the sidebar) |
| Work | It reads code, sees its surroundings, opens code beside it | three tile-pinned lines |
| Tests | Tests run next door | "Tests run next door." |
| Done | Done, then on to the next | "[Done.] All tests pass." then "Done. Next!" |
| Many | Every agent in one list, and one asks for an answer | "Every agent, one list." then "It needs my answer." |
| Lockup | Mark, promise, URL | |

## What makes it work, and what didn't

- Friendly, poppy and expressive: a cursor (the glove when dragging) with a
  bubble when the line is about the cursor. Small punches toward the hand on
  payoffs.
- One thing moves at a time. A line lands on a still frame, and the camera
  never moves under it.
- Didn't work: gesture decorations (circles, trails, rings), pacing too fast
  to follow, and a fake website instead of the real one (TASTE.md, 2026-10-04).
- Every line and sound sits on a mark the recorder logged, so a recapture
  moves them with the picture.
