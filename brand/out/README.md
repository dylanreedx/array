# Campaign direction exports

Each direction includes a parametric SVG mark and lockup, HTML source for every social still, standalone captured app mockup, rendered PNGs at the requested dimensions, and a workflow illustration. `mark.svg` and `lockup.svg` use a different receding-trail count to make the three treatments easy to compare. Compare the full set in [brand/index.html](../index.html).

- `01-infinite` — dark canvas, long mint trail, spatial/technical tone.
- `02-work-in-view` — light canvas, shorter blue trail, clear editorial tone.
- `03-less-hidden` — dark workspace, amber trail, stronger launch energy.

Image names: `og.png` (1200×630), `linkedin-landscape.png` (1200×627), `linkedin-portrait.png` (1080×1350), `x.png` (1600×900), `app-mockup.png` (1600×900), and `flow-zone-agent-approval.png` (1200×630). The real app capture crop is included in each source HTML as an embedded image.

Generated by [render-directions.mjs](../render-directions.mjs). To regenerate, run `node brand/render-directions.mjs` from the repository root with the bundled Node dependencies available.
