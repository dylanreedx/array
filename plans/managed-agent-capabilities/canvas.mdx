  <Annotation
    id="agent-context-note"
    title="Context is per agent"
    targetId="agent-tile-context"
    placement="bottom"
  >

The active backend, `record.cwd`, checkout root, git root, and provider trust state are captured together. A nested Falcon checkout must never resolve from the outer Array project folder.

  </Annotation>

  <Annotation
    id="typed-selection-note"
    title="Selection is an action"
    targetId="skill-picker"
    placement="bottom"
  >

Rows carry typed payloads. Skills invoke provider-owned capabilities; files become validated references; runtime commands call explicit RPCs. Text insertion is only one payload case.

  </Annotation>

  <Annotation
    id="namespace-note"
    title="Three namespaces"
    targetId="runtime-picker"
    placement="bottom"
  >

`$` means skills, `/` means provider templates/commands, and `//` means Array/runtime operations. This prevents a control operation from masquerading as prompt prose.

  </Annotation>

  <Annotation
    id="file-note"
    title="Reuse the safe file path"
    targetId="file-picker"
    placement="bottom"
  >

The picker creates the same `AgentPromptFileReference` and chip used by drag/drop. Absolute transport paths remain host-local and never enter sync metadata.

  </Annotation>
