The current Swift/AppKit source defines the website UI. The complete [component inventory](DEMO_COMPONENT_INVENTORY.md) maps every critical surface, interaction, metric and motion to its native authority. The [storyboard](DEMO_STORYBOARD.md) records the sequence.

Five supporting tiles float into one persistent workspace. The main agent is created through the native Command Center Agent and model steps. It becomes focused before the camera settles and typing begins. The current story focuses on Claude Code and Codex, with consistent provider marks in the tile title, sidebar and footer. Provider choices open from the footer control. Context meters use explicit illustrative fixture values (12%, 18%, 8%), rendered with the native known-usage ring geometry. These are scene data, not live telemetry. Approval moves from Allow once/Decline to Sending, then leaves the transcript.

The workspace uses the native topbar, sidebar, shortcut rail, project zone, status rollup, outer tile titlebars and canvas-owned marching ants. Agent body headers, branch chips, caption-free prose, user authorship rules, activity rows and composers follow current source metrics. The native three-node working glyph advances during paused scroll and stops when inactive, hidden, offscreen or reduced motion. Focus ants also pause offscreen and in hidden documents.

Board lanes, task cards and full-window task details follow their native owners. The editor shows a real 18-line excerpt of CanvasNSView.swift with its actual line numbers and preserves preformatted source on narrow screens. A selected range illustrates inspection; the demo does not fabricate a code insertion. The terminal shows a scripted verification result.

After verification, native settle compacts the layout before the main tile moves into a neighboring slot. `native-layout.ts` ports the Swift move, swap, contact placement, settle and resize geometry. It computes the preview and passive layout together: the separate topmost solid ghost occupies a vacant destination while neighbors make space. Mouse-up re-solves a snapped frame before pinned settle, matching the native call sequence. Swapped tiles retain aligned tops and exact8px contacts, including unequal-width agents. Move gestures suppress the dragged tile’s focus ants and blue emphasis; the editor move gets its own destination ghost. The cursor visibly approaches before pressing and selecting each titlebar or corner. The editor demonstrates a small drag and contact snap back into its aligned slot, and the editor, main agent and terminal each resize substantially with a native-style content-size readout. Tile bodies retain their rectangular geometry. Reverse scroll and direct jumps restore all frames and content from current progress.

The website remains a scripted HTML/SVG/CSS illustration. It does not launch providers or execute commands. Transcript text, elapsed times, model choices, terminal results and board tasks are fixtures. Source-derived dimensions and controls do not reproduce every AppKit interaction, virtualization or keyboard command. Reduced Motion presents six completed cards in normal flow; no JavaScript still leaves explanation and download accessible.

The screen geometrically expands from a rounded Mac preview frame into the full viewport, then contracts back at the end. Native canvas and cursor coordinates are measured inside those current bounds.
